## 变更

- 评论区默认样式改为「纸与墨」：身份字段为横线填写栏，正文直接写在发表卡片上；只保留一个实心主按钮，表情、预览、取消与排序改为文字按钮；圆角 6px / 3px；时间、折叠按钮、字数和页码使用等宽字体；博主标志、链接悬停和表单错误使用朱砂色。Cap 组件保持官方的 260×58px 尺寸，外框圆角跟随 Ecoku 变量。
- 默认的 `--ecoku-*` 变量改为零优先级声明，在 `.ecoku-comments` 上写同名变量即可覆盖，不再需要提高选择器优先级。新增强调色、错误色、圆角、阴影、等宽字体和字号变量，见[自定义样式](../../integration/custom-css)。
- `data-theme="auto"` 不再固定 `color-scheme`，改为继承页面。博客手动切换明暗、与系统设置不一致时，评论区不再出现反色。
- 触屏设备上的输入框字号不小于 16px，避免 iOS 聚焦时放大页面。
- Turnstile 服务端核验收到 HTTP 重定向时，按验证服务不可用处理，请求被拒绝。

## 兼容性

配置项、环境变量、Compose 挂载和密码哈希都没有变化，可以从 v0.2.4 原位升级。评论区的 DOM 类名、文案，以及 SDK 与加载器的接口都不变。

需要注意外观变化：

- 使用默认注入样式或 `/client/ecoku.css` 的站点，评论区外观会随镜像更新。你原有的覆盖 CSS 可能与新默认值叠加，升级后请在浅色和深色模式下各看一遍。以前为了压过默认样式而写的高优先级规则，可以改成在 `.ecoku-comments` 上声明变量。
- `data-css-url` 指向自己的样式表或设为 `none` 的站点，外观不变。
- `/client/` 下的文件缓存一小时，升级后部分访客可能短时间内仍看到旧样式。

## 历史升级事项 {#upgrade}

本版本仅作历史记录，不提供安装或降级步骤。跨 schema 恢复需要与目标版本匹配的完整冷备份；不能只切换镜像。
