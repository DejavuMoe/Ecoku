## 变更

本版以文档修订为主：校正了 API、配置、部署、备份恢复、反向代理和 Twikoo 导入的说明，补充了评论列表的读取预算、逐层读取、限流和状态码说明，使其与 v0.1.9 的实现一致。运行时行为没有变化。

## 兼容性

环境变量、Compose 挂载、端口、容器权限和数据格式都不变，可以从 v0.1.9 原位升级。

## 历史升级事项 {#upgrade}

本版本仅作历史记录，不提供安装或降级步骤。跨 schema 恢复需要与目标版本匹配的完整冷备份；不能只切换镜像。
