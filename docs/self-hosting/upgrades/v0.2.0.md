# v0.2.0

- 发布日期：2026-09-12
- schema：v7，无迁移
- 镜像：`git.via.moe/dejavu/ecoku:v0.2.0`

## 变更

本版以文档修订为主：校正了 API、配置、部署、备份恢复、反向代理和 Twikoo 导入的说明，补充了评论列表的读取预算、逐层读取、限流和状态码说明，使其与 v0.1.9 的实现一致。运行时行为没有变化。

## 兼容性

环境变量、Compose 挂载、端口、容器权限和数据格式都不变，可以从 v0.1.9 原位升级。

## 升级与回滚

按[升级步骤](../upgrade#steps)操作，镜像改为 `git.via.moe/dejavu/ecoku:v0.2.0`。

回滚到 v0.1.9 时，停止服务后把镜像改回 `git.via.moe/dejavu/ecoku:v0.1.9` 再启动，两版 schema 相同。
