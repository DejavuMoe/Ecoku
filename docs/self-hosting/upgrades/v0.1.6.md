# v0.1.6

2026-08-18。Schema 仍为 v6。

## 变更

启用 Cap instrumentation 时，管理端仅在 Cap 为当前方式时额外开放 `script-src 'unsafe-eval'`。关闭或切回 Turnstile 后收回该放宽。`'wasm-unsafe-eval'` 不能代替 JavaScript `'unsafe-eval'`。不接受时关闭 instrumentation 或改用 Turnstile。

升级步骤见 [升级](../upgrade)。自 `v0.1.5`：改 tag 为 `v0.1.6`。无新环境变量或挂载。回滚 `v0.1.5`（同 schema，一般不必换库）。
