# v0.1.6

2026-08-18。Schema 仍为 v6。

## 变更

启用 Cap instrumentation 后，当前 Cap 3.x 生成的脚本会调用 `eval` / `new Function`。管理端仅在 Cap 为当前方式时，为其精确 Origin、WASM、Blob Worker 和 nonce 额外开放 `script-src 'unsafe-eval'`。关闭或切回 Turnstile 后不再放宽 CSP。

`'wasm-unsafe-eval'` 只允许 WebAssembly，不能代替 JavaScript `'unsafe-eval'`。不接受该权衡时，关闭该 Cap Key 的 instrumentation 或改用 Turnstile。

## 升级

无新环境变量或挂载。从 `v0.1.5`：

1. 停服冷备份
2. `compose.yaml` 镜像改为 `v0.1.6`
3. `sudo docker compose pull && sudo docker compose up -d`

若曾为恢复登录而关闭 instrumentation，升级后先确认管理端 CSP 只在 Cap 模式包含 `'unsafe-eval'`，再重新开启，并分别验证登录与评论提交。

回滚改回 `v0.1.5`。两版同为 schema v6，一般不必换库；启动异常仍用停服前备份。
