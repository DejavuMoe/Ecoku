# v0.4.0

- 发布日期：2026-10-09
- schema：v12（无迁移）
- 镜像：`ghcr.io/dejavumoe/ecoku:v0.4.0`
- npm SDK：`ecoku@0.4.0`

## 变更 {#changes}

- 管理后台由 Vue 迁移至 Svelte 5，保留现有布局、功能与简体中文、繁体中文、英语界面。
- 评论区 SDK 继续使用无框架 TypeScript，本次按统一版本号发布；运行时代码与 v0.3.8 相同。

## 兼容性 {#compatibility}

- 没有数据库迁移，schema 仍为 v12。现有评论、站点、管理员账户和设置继续保留。
- 管理地址、HTTP 接口、会话、配置键、环境变量、Compose 挂载和容器端口不变，容器部署不需要额外安装 Node.js 或启动前端服务。
- 已有网站的接入代码无需修改，独立安装的 `ecoku@0.3.8` 可继续使用。通过服务端加载器接入的网站，SDK 随容器镜像更新。

## 升级 {#upgrade}

按 [升级步骤](../upgrade#steps) 停服并冷备份，将镜像改为 `ghcr.io/dejavumoe/ecoku:v0.4.0`，拉取并启动。

检查容器健康状态、启动日志、评论加载和后台登录，再确认站点与通知设置可以正常打开。如果浏览器仍显示旧后台，刷新页面重新加载资源。独立安装的 SDK 可在 npm 发布成功后固定到 `ecoku@0.4.0` 并重新构建网站。

## 回滚 {#rollback}

从 v0.3.8 升级的实例，停服后将镜像改回 `ghcr.io/dejavumoe/ecoku:v0.3.8`，拉取并启动即可恢复 Vue 后台。schema 相同，无需恢复数据库，升级后的评论与设置会保留。独立安装的 SDK 可固定回 `ecoku@0.3.8` 后重新构建网站。

若从更早版本升级，先核对该版本的 schema 与对应版本的回滚说明。
