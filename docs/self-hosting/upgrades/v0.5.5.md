# v0.5.5

本版镜像未通过发布门禁，没有可供部署的正式镜像。请继续使用 [v0.5.4](./v0.5.4)，不要把 `image` 改为 v0.5.5。

- 发布日期：2026-11-09
- schema：v12（无迁移）
- 镜像：未发布
- npm SDK：`ecoku@0.5.5`

## 变更 {#changes}

- 更新 `golang.org/x/net` 至 v0.62.0，修复 Twikoo 导入解析 HTML 时可能出现的二次复杂度漏洞（GO-2026-6860）。
- 更新 Happy DOM、文档开发服务器 Vite 与 SDK 清理工具 rimraf 等构建和测试依赖至修复版本。
- 整理通知队列、管理后台会话与 SDK 加载器的内部状态，对外行为不变。

## 兼容性 {#compatibility}

- 没有数据库迁移，schema 仍为 v12。HTTP 接口、配置键、环境变量、Compose 挂载与容器端口不变。
- 镜像扫描发现运行时基础系统的 musl 与 zlib 存在高危漏洞，镜像未推送版本 tag，`ghcr.io/dejavumoe/ecoku:v0.5.5` 无法拉取。
- npm 上的 `ecoku@0.5.5` 对外行为与 `ecoku@0.5.4` 相同，可与 v0.5.4 服务端配合使用；已固定 `ecoku@0.5.4` 的网站无需更改。

## 升级 {#upgrade}

本版不提供镜像升级入口。现有实例继续运行 v0.5.4，等待下一个修复版本。

## 回滚 {#rollback}

本版没有正式发布的容器镜像，实例不会运行 v0.5.5，无需回滚。已改用 `ecoku@0.5.5` 的网站可固定回 `ecoku@0.5.4` 后重新构建。
