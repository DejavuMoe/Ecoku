# v0.5.0

- 发布日期：2026-10-11
- schema：v12（无迁移）
- 镜像：`ghcr.io/dejavumoe/ecoku:v0.5.0`
- npm SDK：`ecoku@0.5.0`

## 变更 {#changes}

- 评论区根据站点语言更新预览、表情按钮及无障碍标签，SDK 显式指定的语言仍优先。
- 单页应用切换文章后，旧人机验证结果不再触发新文章的提交，旧请求的收尾也不会解除新提交的锁。
- 同页面刷新、排序与分页按请求先后协调，旧响应不会覆盖新列表；首次加载失败仍显示错误。
- 提交期间，已打开或延迟加载的表情面板不能修改正在发送的正文；提交失败后恢复编辑。
- 在 DOM 就绪前执行的加载器会保留自己的脚本地址，继续从同目录加载 SDK。
- 实例密钥全部校验通过后才写入持久文件；无效的首次配置或失败的签名密钥轮换不会先写坏密钥文件。
- Twikoo 导入保留孤儿评论和循环评论的有效后代关系；校验整个文件是单个 JSON 数组且不超过 64 MiB（含末尾空白）；HTML 转成纯文本时保留 `<pre>` 内的缩进、制表符和内部空行。导入后仍按普通评论显示，不提供代码块样式或语法高亮。
- SMTP 服务器确认接收完整邮件后，退出连接失败不再触发重发；保存和测试设置时保留密码首尾空格，留空仍沿用已保存密码。
- 来源比较统一处理默认端口、端口前导零和等价 IPv6 写法，兼容已保存的来源。启动时检查管理来源与数据库内所有站点来源是否重叠。
- 全新数据库应用 YAML 站点种子的 `i18n`，建表、迁移和种子写入在同一事务中完成；既有站点继续使用数据库中的语言设置。
- 管理端首次设密和通知测试遇到失效会话时返回登录；空评论列表回到第 1 页；通知重试保存时清除旧错误，并保留本次部分保存失败的提示。
- 墓碑删除及重复删除响应中的 `has_children` 反映实际直接回复，包括已删除的回复。
- 维护用 API 冒烟脚本通过 Cookie 会话登录，并仅对明确的 `429` 响应按 `Retry-After` 有限重试。

## 兼容性 {#compatibility}

- 没有新增数据库迁移，schema 仍为 v12。管理地址、API 路径、配置键、环境变量、Compose 挂载和容器端口不变。
- 管理来源必须与数据库中所有站点的允许来源分开。已有重叠时，升级前在原后台修正站点来源，或调整管理域名、来源配置和反向代理。新版本发现冲突会拒绝启动，打开数据库的 CLI 子命令也会拒绝继续；见 [配置生效与来源检查](../../reference/configuration#reload)。
- 既有评论、站点、管理员账户和设置继续保留。升级不会自动修复以前写坏的密钥文件、被裁掉空格的 SMTP 密码、错误的站点语言或已导入的评论结构与正文。需要时重新填写正确的 SMTP 密码、在后台修正语言；密钥和历史导入数据应先核对备份，再单独安排恢复，不要删除密钥或数据库来重试升级。
- Twikoo 修复只影响以后执行的导入，仍只接受零评论目标站点；不支持在已有评论上覆盖重导。正文继续按纯文本渲染，不解析 HTML 或 Markdown。
- 新建站点种子的语言来自 YAML；重启或升级不会用 YAML 覆盖既有站点语言。通知仍为至少一次投递，发送后、记录结果前崩溃仍可能导致重复通知。
- 现有接入代码保持兼容。容器内置 SDK 随镜像更新；独立安装的 SDK 需要更新后重新构建网站，才能获得评论区修复。

## 升级 {#upgrade}

按 [升级步骤](../upgrade#steps) 停服并冷备份，将镜像改为 `ghcr.io/dejavumoe/ecoku:v0.5.0`，执行 `sudo docker compose pull && sudo docker compose up -d`。

检查容器健康状态和启动日志，再确认评论加载、排序、分页、文章切换与后台登录。检查通知设置时，如原密码包含首尾空格，请重新输入完整密码、保存并发送测试。Twikoo 迁移仍须先备份、预检，再正式导入；见 [迁移步骤](../twikoo)。

独立安装的 SDK 可在 npm 发布成功后固定到 `ecoku@0.5.0` 并重新构建网站。每个实例都要单独更新镜像，包括为文档示例提供服务的实例。

## 回滚 {#rollback}

从 v0.4.1 升级的实例，停服后将镜像改回 `ghcr.io/dejavumoe/ecoku:v0.4.1`，拉取并启动即可。schema 相同，无需恢复数据库，升级后的评论与设置会保留；本次修复也会随程序回滚而失去。独立安装的 SDK 可固定回 `ecoku@0.4.1` 后重新构建网站。

若从更早版本升级，先核对该版本的 schema 与对应版本的回滚说明。
