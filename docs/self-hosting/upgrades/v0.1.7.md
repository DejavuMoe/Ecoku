# v0.1.7

2026-08-26。Schema 仍为 v6。

## 变更

本版本更新本地开发、CI 与容器构建工具链，以及文档站的构建/发布流程。工具链固定为 Node.js 24.19.0、Go 1.27.0、pnpm 11.24.0；运行时镜像仍为 Alpine 3.24.1。应用运行时契约没有改变。

## 升级

本版本不新增环境变量、配置键或 Compose 挂载。容器仍以 UID/GID `10001:10001` 运行，`/data`、配置与日志挂载路径保持不变，因此现有 `v0.1.6` 实例不需要调整权限。

不要整体覆盖现有 Compose 文件；保留现有资源限制和挂载，只把精确镜像 tag 改为 `git.via.moe/dejavu/ecoku:v0.1.7`。旧文件没有 `logging` 段时，按当前仓库补上。

从 `v0.1.6` 升级：

1. 停止服务并冷备份 `data/`、`app/config.yaml`、`app/logs/`、`ecoku.env` 和当前 Compose 文件。
2. 修改精确镜像 tag 为 `v0.1.7`。
3. 执行：

```bash
sudo docker compose config --quiet
sudo docker compose pull
sudo docker compose up -d
sudo docker compose ps
sudo docker compose logs --tail=200 ecoku
curl --fail http://127.0.0.1:12123/api/health
```

回滚时改回 `v0.1.6`。两版同为 schema v6，一般不必替换数据库；若启动或验证异常，仍使用停服前备份恢复。
