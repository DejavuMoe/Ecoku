# v0.3.6

本版镜像未通过发布门禁，没有可供部署的正式镜像。请使用 [v0.3.7](./v0.3.7)。

- 发布日期：2026-10-06
- schema：v12（无迁移）
- 镜像：未发布
- npm SDK：`ecoku@0.3.6`

## 变更 {#changes}

- 公共评论列表跳过叶节点的无效查询，管理列表复用状态统计，保留排序、分页和读取上限。
- 评论删除与通知最终发送协调，发送前重新检查状态；删除父评论后，已发送直接回复的 Telegram 消息会排队移除父引用，保留回复正文。
- 登录配置、管理查询和通知 worker 继承取消信号；补齐 Cap IPv6 地址检查，密钥文件替换失败时保留旧文件。
- 源码启动默认仅监听 `127.0.0.1`；开发演示页固定连接本机 API。
- 优化 Docker 构建阶段和 CI 依赖安装；固定基础镜像 digest，并为双架构发布增加运行检查、SBOM 和漏洞扫描。
- 更新 Vue 至 `3.5.42`、`source-map-js` 至 `1.2.2`，修复依赖审计发现的高危漏洞。

## 兼容性 {#compatibility}

- 没有数据库迁移，schema 仍为 v12。Compose 挂载、配置键、环境变量和容器监听方式不变。
- 源码模式不再默认对局域网开放；容器部署继续按现有 Compose 端口和反向代理配置访问。
- 删除可能等待已经开始的通知投递结束，单笔投递期限为 20 秒。已发送邮件不能召回，Telegram 更新异步完成；完整边界见 [删除评论之后](../../admin/notifications#after-deletion)。
- HTTP 接口和生产 SDK 保持兼容，独立接入的 `ecoku@0.3.5` 可继续使用。

## 升级 {#upgrade}

本版不提供镜像升级入口。从 v0.3.5 或更早版本升级时，请按 [v0.3.7 升级说明](./v0.3.7#upgrade) 操作。

## 回滚 {#rollback}

本版没有正式发布的容器镜像。现有实例可继续运行已部署版本，升级与回滚以 [v0.3.7 说明](./v0.3.7#rollback) 为准。
