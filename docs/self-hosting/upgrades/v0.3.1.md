# v0.3.1

- 发布日期：2026-10-03
- schema：v11 → v12
- 镜像：`ghcr.io/dejavumoe/ecoku:v0.3.1`
- npm SDK：`ecoku@0.3.1`

## 变更 {#changes}

- 后台与评论区增加简体中文、繁体中文和英语。后台通过 `ECOKU_ADMIN_LOCALE` 选择语言；站点保存评论区默认语言，SDK 的 `i18n` 参数优先覆盖站点设置。
- 文档移除日语，保留三语；首页根据浏览器语言选择入口，无法识别时使用英语。Demo 评论区跟随文档手动明暗切换。
- 取消切换文章和评论翻页的成功提示，保留分页页码播报、发布成功与错误反馈。邮件品牌与排版对齐后台。

## 兼容性 {#compatibility}

- 在 `sites` 表增加 `i18n_locale`，已有站点默认 `zh-CN`。保留现有评论、账户、密钥和通知配置，无需重新初始化。
- 后台语言默认 `zh-CN`；可选 `zh-Hant`、`en`。现有 Compose 不增加该变量也可升级。
- 评论区语言优先级：SDK `i18n` → 站点设置 → `zh-CN`。用户自定义文案保持原文。
- schema 没有向下迁移，v0.3.0 无法打开已升级到 v12 的数据库。

## 升级 {#upgrade}

1. 停服并 [冷备份](../backup#cold-backup) 数据库、`ecoku-secrets.json`、Compose 和配置文件。
2. 按 [升级步骤](../upgrade#steps) 将镜像改为 `ghcr.io/dejavumoe/ecoku:v0.3.1`，执行 `sudo docker compose pull && sudo docker compose up -d`。
3. 检查容器健康状态、管理员登录、历史评论、站点与通知配置；确认 schema v12 迁移成功。
4. npm 发布成功后，使用 `pnpm add --save-exact ecoku@0.3.1` 更新独立接入的 SDK 并重新构建网站。容器内置 SDK 随镜像更新。

## 回滚 {#rollback}

停服后将镜像改回 `ghcr.io/dejavumoe/ecoku:v0.3.0`，按 [恢复说明](../backup#restore) 还原升级前同一份数据库与持久密钥备份，再启动并检查。不能只改镜像 tag；备份之后新增的评论和配置修改会丢失。
