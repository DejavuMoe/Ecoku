# v0.1.3

- 发布日期：2026-08-15
- schema：v4 → v5
- 镜像：`git.via.moe/dejavu/ecoku:v0.1.3`

## 变更

- 博主改为口令认证：在评论区昵称栏填写口令即以博主身份发布。
- 通知在入队时按收件人拆成多条记录，逐条重试；通知进程启动时回收所有“处理中”的记录。
- SMTP 只允许 TLS 或 STARTTLS。
- 站点管理密钥不能再读取评论列表和详情（返回 `403`），只保留对本站评论的墓碑删除。
- `trusted_proxies` 禁止填写 `0.0.0.0/0` 或 `::/0`。

## 兼容性

schema v5 增加博主口令哈希、评论的博主标记，以及通知队列的收件目标字段。在 v0.1.3 中，为站点设置博主口令时会按博主昵称和邮箱回填历史评论的博主标记。

升级后需要在后台为站点设置博主口令，才能继续以博主身份发言。

## 升级

1. 按[备份与恢复](../backup#cold-backup)停服并做冷备份。
2. 按[升级步骤](../upgrade#steps)操作，镜像改为 `git.via.moe/dejavu/ecoku:v0.1.3`。
3. 登录后台，为需要的站点设置博主口令。

## 回滚

数据库迁移到 v5 后，v0.1.2 无法打开。回滚需要把镜像改回 `v0.1.2`，并用升级前的冷备份[恢复](../backup#restore)。
