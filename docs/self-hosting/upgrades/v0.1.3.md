# v0.1.3

2026-08-15。Schema **v4 → v5**。

## 变更

- 博主改为口令证明：公开区只在昵称栏填口令。
- 通知按入队时每个收件人拆成 outbox 行；worker 启动收回全部 `processing` 行。
- SMTP 只允许 TLS / STARTTLS。
- management key 对评论 GET 列表/详情返回 403，只保留所属站点墓碑删除。
- 禁止 `trusted_proxies` 为 `0.0.0.0/0` 或 `::/0`。

迁移增加博主口令哈希、`comments.is_blogger`、outbox `target`。启动后在管理端设置口令，会回填历史博主评论。

升级步骤见 [升级](../upgrade)。自 `v0.1.2`：改 tag 为 `v0.1.3`。回滚必须换回 `v0.1.2` **并** 用停服前整库备份恢复；已写入 v5 的库不能跑在 `v0.1.2` 上。
