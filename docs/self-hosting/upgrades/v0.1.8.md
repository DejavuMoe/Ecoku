# v0.1.8

- 发布日期：2026-08-27
- schema：v6 → v7
- 镜像：`git.via.moe/dejavu/ecoku:v0.1.8`

## 变更

- 站点可以启用 Smoji 表情包，并填写一个远程 v1 清单 URL。访客首次打开表情选择器时才加载清单；表情图片不打包进 Ecoku 镜像。
- 生产环境的清单 URL 必须是 HTTPS，表情图片必须与清单同源。
- 选中的表情以 `![smoji:名称](完整图片地址)` 的纯文本形式保存。关闭功能后，历史标记按原文显示。

## 兼容性

schema v7 为站点表增加 Smoji 开关和清单地址两个字段，已有站点默认关闭。没有新的环境变量、配置项、挂载或权限要求。

## 升级

1. 按[备份与恢复](../backup#cold-backup)停服并做冷备份。
2. 按[升级步骤](../upgrade#steps)操作，镜像改为 `git.via.moe/dejavu/ecoku:v0.1.8`。启动时自动迁移到 v7。
3. 检查评论区和管理后台。

## 回滚

数据库迁移到 v7 后，v0.1.7 无法打开。回滚需要停止服务，用升级前的冷备份[恢复](../backup#restore)，再以 v0.1.7 启动。备份之后的新数据会丢失。
