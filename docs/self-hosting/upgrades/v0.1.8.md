# v0.1.8

2026-08-27。Smoji 表情包可按站点启用，配置一个远程 v1 清单 URL。选择器按需加载清单，表情资源不打包进 Ecoku 镜像；生产清单 URL 必须使用 HTTPS，图片须与清单同源。

Schema 从 v6 原位、事务性升级到 v7，为 `sites` 增加 `smoji_enabled` 与 `smoji_manifest_url`。已有站点默认关闭且清单为空；无新增环境变量、配置键、Compose 挂载或容器权限要求。

升级步骤见 [升级](../upgrade)。自 `v0.1.7`：停服冷备份后，把 Compose 的精确 tag 改为 `v0.1.8`，执行 `sudo docker compose config --quiet`、`sudo docker compose pull`、`sudo docker compose up -d`，再检查日志、`docker compose ps` 与 `/api/health`，并验证评论与管理端。启动时会自动执行 v6 → v7 迁移。

回滚不能只把 tag 改回 `v0.1.7`；若新版本已写入 v7，必须停服并恢复升级前的整库备份，再用 `v0.1.7` 启动。
