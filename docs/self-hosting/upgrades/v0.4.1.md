# v0.4.1

- 发布日期：2026-10-09
- schema：v12（无迁移）
- 镜像：`ghcr.io/dejavumoe/ecoku:v0.4.1`
- npm SDK：`ecoku@0.4.1`

## 变更 {#changes}

- 移除后台全局快捷键及提示，包括评论导航、查看原评论、删除确认、刷新和保存设置的快捷键。继续使用页面上的对应按钮；表单、菜单和按钮的基本键盘操作保留。
- npm 包首页的安装示例同步至 `ecoku@0.4.1`，补齐 SDK 包内更新日志，并加入发布一致性校验。

## 兼容性 {#compatibility}

- 没有数据库迁移，schema 仍为 v12。管理地址、HTTP 接口、会话、配置键、环境变量、Compose 挂载和容器端口不变。
- 现有评论、站点、管理员账户和设置继续保留。删除确认与离开未保存设置时的提醒仍通过原有界面完成。
- 评论区 SDK 继续使用无框架 TypeScript，运行时代码与 v0.4.0 相同；已有接入代码无需修改，独立安装的 `ecoku@0.4.0` 可继续使用。

## 升级 {#upgrade}

按 [升级步骤](../upgrade#steps) 停服并冷备份，将镜像改为 `ghcr.io/dejavumoe/ecoku:v0.4.1`，拉取并启动。

检查容器健康状态、启动日志、评论加载和后台登录；刷新后台页面，确认快捷键提示已移除，列表与设置按钮正常显示。容器内置 SDK 随镜像更新；独立安装的 SDK 可在 npm 发布成功后固定到 `ecoku@0.4.1` 并重新构建网站。

## 回滚 {#rollback}

从 v0.4.0 升级的实例，停服后将镜像改回 `ghcr.io/dejavumoe/ecoku:v0.4.0`，拉取并启动即可。schema 相同，无需恢复数据库，升级后的评论与设置会保留；旧版的后台快捷键及提示也会恢复。独立安装的 SDK 可固定回 `ecoku@0.4.0` 后重新构建网站。

若从更早版本升级，先核对该版本的 schema 与对应版本的回滚说明。
