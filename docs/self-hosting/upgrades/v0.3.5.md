# v0.3.5

- 发布日期：2026-10-05
- schema：v12（无迁移）
- 镜像：`ghcr.io/dejavumoe/ecoku:v0.3.5`
- npm SDK：`ecoku@0.3.5`

## 变更 {#changes}

- 管理后台切换「评论」「站点」「通知」「安全」时预留滚动条位置，修复长短页面切换和数据加载导致的整页横向抖动。

## 兼容性 {#compatibility}

- 没有数据库迁移，schema 仍为 v12。Compose 挂载、配置项和环境变量不变。
- 修复只涉及管理后台样式。HTTP 接口和 SDK 运行时与 v0.3.4 相同；独立接入的 `ecoku@0.3.4` 可继续使用。

## 升级 {#upgrade}

1. 停服并 [冷备份](../backup#cold-backup) 数据库、`ecoku-secrets.json`、Compose 和配置文件。
2. 按 [升级步骤](../upgrade#steps) 将镜像改为 `ghcr.io/dejavumoe/ecoku:v0.3.5`，执行 `sudo docker compose pull && sudo docker compose up -d`。
3. 检查容器健康状态；刷新管理后台，在四个菜单之间来回切换，确认页面不再因滚动条出现或消失而横移。
4. 如需统一 SDK 版本，等 npm 发布成功后使用 `pnpm add --save-exact ecoku@0.3.5` 并重新构建网站。容器内置 SDK 随镜像更新。

## 回滚 {#rollback}

schema 没有变化。停服后将镜像改回 `ghcr.io/dejavumoe/ecoku:v0.3.4`，拉取并启动即可，不需要恢复数据库；升级后新增的评论和设置修改会保留。回滚会撤回本版的后台抖动修复；独立安装的 npm SDK 可固定回 `ecoku@0.3.4` 后重新构建网站。
