# v0.1.5

2026-08-17。Schema **v5 → v6**。

## 变更

实例级机器人验证改为关闭 / Turnstile / 自托管 Cap 三态，同时保护评论与管理员登录。浏览器提交单次 `captchaToken`。增加停服命令 `captcha status` / `captcha disable`。

管理端 CSP 为 Cap 实例 Origin、WASM、Blob Worker 和 instrumentation 生成精确 nonce。Cap HTTPS Siteverify 拒绝重定向、localhost、私网和非公网解析。

## 升级

迁移把 `turnstile_settings` 重命名为 `captcha_settings`，保留开关、Sitekey、加密 Secret，默认 provider 为 Turnstile，再增加 Cap 字段。

必须停服冷备份。已写入 v6 的库不能只换回旧镜像。

从 `v0.1.4`：改精确 tag 为 `v0.1.5` 后 `pull && up -d`。若选择 Cap，在 Cap Key 中允许管理端与全部评论站点 Origin，并验证 Widget、登录和提交。

回滚必须恢复停服前整库备份。
