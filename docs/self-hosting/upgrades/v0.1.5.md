# v0.1.5

- 发布日期：2026-08-17
- schema：v5 → v6
- 镜像：`git.via.moe/dejavu/ecoku:v0.1.5`

## 变更

- 人机验证改为实例级三选一：关闭、Cloudflare Turnstile、自托管 Cap，同时保护评论提交和管理员登录。
- 浏览器提交一次性的 `captchaToken`。
- 新增命令行 `captcha status` 和 `captcha disable`，用于验证配置出错时恢复登录，见[命令行](../../reference/cli#captcha-disable)。
- 管理后台的 CSP 按当前验证方式调整；Cap 需要放行实例来源、WebAssembly 和 Blob Worker。

## 兼容性

schema v6 把原来的 `turnstile_settings` 表重命名为 `captcha_settings`，保留开关和密钥，默认验证方式为 Turnstile，并增加 Cap 相关字段。

如果改用 Cap，要在 Cap key 中允许管理后台和所有评论站点的来源。

## 升级

1. 按[备份与恢复](../backup#cold-backup)停服并做冷备份。
2. 按[升级步骤](../upgrade#steps)操作，镜像改为 `git.via.moe/dejavu/ecoku:v0.1.5`。

## 回滚

数据库迁移到 v6 后，v0.1.4 无法打开。回滚需要用升级前的冷备份[恢复](../backup#restore)。
