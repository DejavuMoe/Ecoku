# v0.1.5

2026-08-17。Schema **v5 → v6**。

## 变更

- 实例级验证改为关闭 / Turnstile / 自托管 Cap 三态，同时保护评论与管理员登录。
- 浏览器提交单次 `captchaToken`。
- 增加停服命令 `captcha status` / `captcha disable`。
- 管理端 CSP 按当前提供方收敛；Cap 需实例 Origin、WASM、Blob Worker。

迁移把 `turnstile_settings` 重命名为 `captcha_settings`，保留开关与密钥，默认 provider 为 Turnstile，再增加 Cap 字段。

升级步骤见 [升级](../upgrade)。自 `v0.1.4`：改 tag 为 `v0.1.5`。若用 Cap，在 Cap Key 中允许管理端与全部评论站点 Origin。回滚必须恢复停服前整库备份；已写入 v6 的库不能只换回旧镜像。
