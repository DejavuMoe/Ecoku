# v0.2.3

- 发布日期：2026-09-16（Git tag）
- schema：v7，无迁移
- 镜像：`git.via.moe/dejavu/ecoku:v0.2.3`

## 变更

- 保存站点设置时不再重新授予历史评论博主身份。博主口令增加“UTF-8 编码不超过 72 字节”的校验，已设置的口令继续有效。
- SMTP 发送的全过程都可以取消，并受 20 秒超时约束。通知发出后如果写回状态失败，只重试写回，不重复发送。Telegram 消息保留完整链接和 HTML 结构。
- Twikoo 导入在记录乱序时也能正确还原父子关系。
- 评论和后台输入支持完整的 Unicode 字符；后台请求的取消与超时处理、加载器重试、Smoji 地址与键盘操作等多项修复。
- SDK 的 `setPageKey(pageKey, pageTitle)` 可以同时更新文章标题；省略第二个参数会清空旧标题。

## 兼容性

挂载、环境变量和密码哈希格式不变，可以从 v0.2.2 原位升级。不会清理评论、配置、WAL 文件或备份。

- 已有的博主标记保持不变。旧版本在保存站点时可能误标过一些评论，这些记录无法与真正用口令发布的评论自动区分，本版本不会批量修改。如果发现误标，需要单独核实后处理。
- 通知按“至少一次”投递：进程在发出通知后、记录结果前崩溃，重启后可能重复发送一次。

## 升级

按[升级步骤](../upgrade#steps)操作，镜像改为 `git.via.moe/dejavu/ecoku:v0.2.3`。启动后确认能登录后台、历史评论和博主标志显示正常。如需验证通知，请手动发送测试邮件或测试消息。

## 回滚到 v0.2.2

两版都是 schema v7。停止服务，把镜像改回 `git.via.moe/dejavu/ecoku:v0.2.2`，拉取并启动，现有数据库和新评论都会保留。本版修复的问题也会随之恢复。
