# v0.6.4

- 发布日期：2026-11-26
- schema：v12（无迁移）
- 镜像：`ghcr.io/dejavumoe/ecoku:v0.6.4`
- npm SDK：`ecoku@0.6.4`

## 变更 {#changes}

- 管理后台评论页在「已发布 / 已删除」右侧新增搜索框，可在当前站点、当前一栏内按昵称、邮箱、访客网站、正文、文章标题、页面 key 或 `#编号` 查找，多个词须全部命中，命中的词以底色标出。用法见 [搜索评论](../../admin/comments#search)。
- 后台评论列表接口 `GET /api/admin/sites/:siteId/comments` 新增 `q` 参数；带 `q` 时计数与分页只统计匹配的评论，见 [HTTP 接口](../../reference/api)。

## 兼容性 {#compatibility}

- schema 保持 v12。从 v0.6.3 升级时，沿用现有数据与配置挂载、容器用户和健康探针；配置项不变。
- 已删除的评论只保留文章标题、页面 key 和编号，搜索时只按这三项匹配。
- 搜索词只随请求发送，不写入页面地址或浏览器存储；访问日志只记录路由模板，不记录搜索词。
- npm SDK `ecoku@0.6.4` 的运行时代码与 0.6.3 相同。
- 从 v0.5.7 或更早版本升级时，先阅读 [distroless 迁移说明](../upgrade#distroless)，同步更换旧 Compose 探针。

## 升级 {#upgrade}

按 [升级步骤](../upgrade#steps) 停服并冷备份，将镜像改为 `ghcr.io/dejavumoe/ecoku:v0.6.4`，再拉取并重建容器。确认状态为 `healthy`，登录后台查看底部版本号为 `v0.6.4`，在评论页搜索一条已知评论的昵称或正文，确认能找到并标出命中的词。通过 npm 引入 SDK 的站点，将依赖改为 `ecoku@0.6.4`。

## 回滚 {#rollback}

停止服务，将镜像改回 `ghcr.io/dejavumoe/ecoku:v0.6.3`，再拉取并重建容器。两个版本均使用 schema v12，保留现有数据库与健康探针即可。
