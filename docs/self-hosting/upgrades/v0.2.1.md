# v0.2.1

::: warning 内测版本，请勿使用
仅保留版本标签、变更和历史升级事项。公开部署从 v0.3.0 开始；旧镜像不再提供部署支持。请使用 [当前部署文档](../docker)。
:::

- 发布日期：2026-09-12
- schema：v7，无迁移
- Git tag: [v0.2.1](https://github.com/DejavuMoe/Ecoku/tree/v0.2.1)

## 变更

- Smoji 清单容量提高到 64 个分组、每组 600 项、总计 6000 项，文件上限 1 MiB（按 UTF-8 字节计）。8 秒超时覆盖完整下载；增加 JSON 类型、标签控制字符和图片地址校验。
- 清单新增可选的 `base` 地址模板，条目可以省略重复的 `src`。旧格式继续支持，见 [Smoji 表情包](../../integration/smoji#base)。

## 兼容性

配置、环境变量和挂载不变，可以从 v0.2.0 原位升级。旧清单无需修改。

使用 `base` 模板的清单在 v0.2.0 上无法解析。如果需要回滚，请保留一份逐项写 `src`、且不超出 v0.2.0 容量（32 组、每组 300 项、总计 2000 项、256 KiB）的清单。

## 历史升级事项 {#upgrade}

本版本仅作历史记录，不提供安装或降级步骤。跨 schema 恢复需要与目标版本匹配的完整冷备份；不能只切换镜像。
