## 升级影响

- SQLite 保持 **schema v7**，无数据库迁移。
- 环境变量、Compose 挂载、端口和容器权限不变。
- Smoji 清单上限调整为 64 包、每包 600 项、总计 6000 项和 1 MiB UTF-8；新增可选 `base` 模板。旧清单继续兼容。

## 升级操作

1. 停服并备份 `data/`、`app/config.yaml`、`ecoku.env` 与原 `compose.yaml`。
2. 将镜像改为 `git.via.moe/dejavu/ecoku:v0.2.1`。
3. 执行 `sudo docker compose config --quiet && sudo docker compose pull && sudo docker compose up -d`，然后检查日志、健康接口和评论区。

## 回滚到 v0.2.0

停服后恢复精确 `v0.2.0` 镜像 tag，拉取并启动。两版均为 schema v7，通常无需恢复数据库。
