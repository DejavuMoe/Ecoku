# 處理評論

Ecoku 沒有審核佇列，評論送出後立即公開。你在後台「評論」頁查看所有評論，刪掉不該留下的。

## 查看評論

「評論」頁分「已發布」和「已刪除」兩欄，每頁 20 則，依日期分組，可以切換最新或最早在前。每則評論顯示：

- 內文、時間、文章標題和頁面 key
- 訪客填寫的信箱和網站（這些不會公開）
- 如果是回覆，引用它回覆的那則評論

點「查看原評論」會在新分頁開啟文章，並跳到這則評論。

## 搜尋評論 {#search}

評論較多時，用「已發布 / 已刪除」右側的搜尋框查找。搜尋只在目前站點、目前一欄中進行：

- 依暱稱、信箱、訪客網站、內文、文章標題或頁面 key 查找，英文字母不分大小寫。
- 用空格分開多個詞時，每個詞都要符合，可以分別出現在不同項目裡，例如 `上海 Alice`。只取前 8 個不同的詞，整段最多 100 個字元。
- 輸入 `#123` 查找編號為 123 的評論，編號顯示在每則評論的右下方。
- 已刪除的評論只保留文章標題、頁面 key 和編號，只能依這三項查找。

停止輸入片刻後自動搜尋，按 Enter 立即搜尋；按 Esc 或點搜尋框右側的清除按鈕回到全部評論。搜尋時，標題和兩欄的數字都改為符合的則數，符合的詞以底色標出。翻頁、切換排序、切換「已發布 / 已刪除」和重新整理都保留目前的搜尋，切換站點會清除搜尋。

## 刪除評論 {#delete}

刪除有兩種，都 **不能復原**。

| | 墓碑刪除 | 徹底刪除 |
| --- | --- | --- |
| 在哪裡 | 「已發布」裡的任何評論 | 「已刪除」裡沒有回覆的評論 |
| 結果 | 清空暱稱、信箱、網址和內文，保留它在討論中的位置 | 從資料庫中移除 |
| 訪客看到 | 「已刪除」和「[此評論已刪除]」，下面的回覆照常顯示 | 評論消失 |

先墓碑刪除，是為了不讓下面的回覆失去上下文。墓碑下面還有回覆時不能徹底刪除，後台會顯示「仍有回覆，不能徹底刪除」。

被墓碑刪除的評論不能再被回覆。

## 刪除對通知的影響

刪除一則評論後，與它有關、還沒寄出的通知不再傳送；已經傳送的 Telegram 訊息會被改寫為刪除提示。已經寄出的電子郵件無法撤回。詳見 [通知 · 刪除評論之後](./notifications#after-deletion)。

## 用腳本刪除評論

需要用自動化腳本刪評論時，可以給站點設定一個站點管理憑證，它只能對這個站點的評論做墓碑刪除。見 [設定檔](../reference/configuration) 中 `sites[].management_key_env` 的註解，以及 [HTTP API · 驗證方式](../reference/api#auth)。
