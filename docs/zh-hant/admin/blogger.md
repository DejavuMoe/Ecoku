# 部落客身分

部落客不需要單獨的帳號。給站點設定一個口令後，你在自己部落格的評論區裡把口令填進暱稱欄，就能以部落客身分發言，評論帶上部落客標誌。

<div class="steps">

### 在站點裡填寫部落客資訊

在後台「站點」裡編輯站點，找到部落客相關欄位：

| 欄位 | 說明 |
| --- | --- |
| 博主暱稱 | 公開顯示的名字，最多 80 個字元 |
| 博主信箱 | 不公開，儲存為部落客評論的信箱。部落客通知寄到「通知」頁的收件人，不是這裡。 |
| 博主口令 | 12～80 個字元，不超過 72 個 UTF-8 位元組，不能換行。儲存後不再顯示，留空表示不修改。 |
| 評論區標誌 | 顯示在暱稱後的文字，預設 `[博主]`，最多 16 個字元，留空則不顯示 |

暱稱和信箱要麼都填，要麼都留空；都填時必須設定口令。

### 在評論區發言

在部落格的評論框裡：

- **暱稱**：填部落客口令
- **信箱**、**網址**：留空

直接發布。伺服器認出口令後，會把這則評論的暱稱、網址、信箱換成部落客暱稱、站點 URL 和部落客信箱，並加上部落客標誌。瀏覽器不會把口令記成你的暱稱。

</div>

::: warning 口令輸錯時
輸錯的口令會被當成一般暱稱。如果站點的信箱是選填，這則評論會以口令文字為暱稱公開發布。發現後到「評論」裡刪掉它，並更換口令。
:::

## 關閉部落客身分

把部落客暱稱和信箱都清空並儲存，口令也會一起清除。

## 已有評論的標記

部落客標記在評論儲存時寫入，之後不再重新計算。改暱稱、換口令，都不會影響已有評論的標記。

只有兩種情況會依暱稱和信箱回填歷史評論：

- 從舊版本升級到 schema v5 時的一次性遷移；
- [從 Twikoo 匯入](../self-hosting/twikoo) 時，暱稱完全一致且信箱一致（不區分大小寫）的評論會標為部落客評論。

部落客的評論不會觸發給你自己的通知，規則見 [通知 · 什麼時候傳送](./notifications#when)。
