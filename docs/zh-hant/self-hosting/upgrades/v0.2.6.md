# v0.2.6

- 發布日期：2026-09-29
- schema：v8，無遷移
- 映像：`git.via.moe/dejavu/ecoku:v0.2.6`

## 變更

- 管理後台改用與評論區預設樣式相同的紙墨配色（淺色與深色），圓角 6px / 3px；介面字型改為作業系統內建的中英文字型，不載入網路字型。
- 站點切換從頂欄移到「评论管理」清單左上角；只有一個站點時直接顯示站點名稱。「通知设置」與「安全」頁面不再顯示站點選擇。
- 「评论管理」：「查看原评论」「墓碑删除」「彻底删除」移到詳細資訊頂端；仍有回覆的墓碑會顯示「仍有回复，不能彻底删除」；刪除確認框列出目標評論；清單增加載入中與載入失敗狀態，失敗時可以重試；可以用上下方向鍵在清單中切換評論。
- 「站点管理」：表單依基本資訊、評論區、貼圖包、部落客身分分組，儲存按鈕固定在底部，驗證失敗時顯示需要修改的數量並定位到第一處錯誤。
- 「通知设置」：加密方式改為 SSL/TLS 與 STARTTLS 兩項選擇；管道關閉時收起欄位；移除固定勾選的「访客收到回复时」選項，訪客回覆通知仍隨電子郵件管道一起開關。
- 文件網站依原始碼重寫，見[升級說明](../upgrade)與各頁面。

## 相容性

設定項、環境變數、Compose 掛載、管理介面和資料庫都沒有變化，可以從 v0.2.5 原地升級。評論區與 SDK 不受影響。

後台頁面本身不快取，升級後重新整理即可看到新介面；已經開啟的後台分頁需要重新整理一次。

## 升級

依[升級步驟](../upgrade#steps)操作，映像改為 `git.via.moe/dejavu/ecoku:v0.2.6`。啟動後登入後台，依序開啟四個頁面，在淺色和深色下各看一遍。

## 回滾到 v0.2.5

兩版都是 schema v8。停止服務，把映像改回 `git.via.moe/dejavu/ecoku:v0.2.5`，拉取並啟動即可，現有資料庫和升級後的新評論都會保留。後台介面隨之回到舊版。
