## 變更

- 通知郵件改用與評論區、管理後台相同的紙墨配色（支援深色模式），文字使用系統內建的中英文無襯線字型，Windows 郵件用戶端中的中文不再顯示為宋體。
- 郵件主旨附帶文章標題，如「您在 [站点名称] 上有新评论：[文章标题]」；新回覆與訪客回覆郵件也會顯示文章標題和時間。時間依容器的 `TZ` 顯示並註明時區偏移，不再固定為 UTC。
- 表情包在郵件中顯示為圖片或 `[表情：标签]`，不再顯示原始標記。
- Telegram 通知增加發布時間，被回覆的評論以引用區塊顯示；內文上限改為 1000 個字元。
- 刪除評論後，尚未寄出的通知不再寄送，已寄出的 Telegram 訊息會被改寫為「这条评论已被删除，通知内容已移除。」。已寄出的郵件無法撤回。詳見[刪除評論之後](../notifications#after-deletion)。
- 收件信箱被拒或 Telegram 對話不可用時不再重複嘗試；已完成的通知紀錄保留 30 天後自動清理。
- 文件依原始碼核對，修正了介面、命令列、備份還原與常見問題中的多處說明。

## 相容性

- schema v9 原位重建通知佇列資料表 `notification_outbox`，增加新的狀態、事件類型、訊息 ID 欄位與索引。評論、站點和設定不變，佇列中的紀錄與編號全部保留；已用完 8 次嘗試的失敗紀錄改為「已放棄」。
- 設定項、環境變數、Compose 掛載、管理介面、評論區與 SDK 都沒有變化。
- 升級前已寄出的 Telegram 訊息沒有記錄訊息 ID，之後刪除對應評論時無法改寫。

## 歷史升級事項 {#upgrade}

本版本僅作歷史記錄，不提供安裝或降級步驟。跨 schema 還原需要與目標版本相符的完整冷備份；不能只切換映像檔。
