# v0.3.5

- 發布日期：2026-10-05
- schema：v12（無遷移）
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.3.5`
- npm SDK：`ecoku@0.3.5`

## 變更 {#changes}

- 管理後台切換「評論」「站點」「通知」「安全」時預留捲軸位置，修正長短頁面切換和資料載入導致的整頁橫向晃動。

## 相容性 {#compatibility}

- 沒有資料庫遷移，schema 仍為 v12。Compose 掛載、設定項和環境變數不變。
- 修正只涉及管理後台樣式。HTTP 介面和 SDK 執行階段與 v0.3.4 相同；獨立接入的 `ecoku@0.3.4` 可繼續使用。

## 升級 {#upgrade}

1. 停服並 [冷備份](../backup#cold-backup) 資料庫、`ecoku-secrets.json`、Compose 和設定檔。
2. 按 [升級步驟](../upgrade#steps) 將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.3.5`，執行 `sudo docker compose pull && sudo docker compose up -d`。
3. 檢查容器健康狀態；重新整理管理後台，在四個選單之間來回切換，確認頁面不再因捲軸出現或消失而橫移。
4. 如需統一 SDK 版本，等 npm 發布成功後使用 `pnpm add --save-exact ecoku@0.3.5` 並重新建置網站。容器內建 SDK 隨映像檔更新。

## 回滾 {#rollback}

schema 沒有變化。停服後將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.3.4`，拉取並啟動即可，不需要還原資料庫；升級後新增的評論和設定修改會保留。回滾會撤回本版的後台晃動修正；獨立安裝的 npm SDK 可固定回 `ecoku@0.3.4` 後重新建置網站。
