# v0.1.5

2026-08-17。Schema **v5 → v6**。

## 變更

實例級機器人驗證改為關閉 / Turnstile / 自託管 Cap 三態，同時保護評論與管理員登入。瀏覽器送出單次 `captchaToken`。增加停服命令 `captcha status` / `captcha disable`。

管理端 CSP 為 Cap 實例 Origin、WASM、Blob Worker 和 instrumentation 生成精確 nonce。Cap HTTPS Siteverify 拒絕重定向、localhost、私網和非公網解析。

## 升級

遷移把 `turnstile_settings` 重命名為 `captcha_settings`，保留開關、Sitekey、加密 Secret，預設 provider 為 Turnstile，再增加 Cap 欄位。

必須停服冷備份。已寫入 v6 的庫不能只換回舊鏡像。

從 `v0.1.4`：改精確 tag 為 `v0.1.5` 後 `pull && up -d`。若選擇 Cap，在 Cap Key 中允許管理端與全部評論站點 Origin，並驗證 Widget、登入和送出。

回滾必須恢復停服前整庫備份。
