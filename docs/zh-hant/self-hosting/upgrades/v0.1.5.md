# v0.1.5

2026-08-17。Schema **v5 → v6**。

## 變更

- 執行個體級驗證改為關閉 / Turnstile / 自託管 Cap 三態，同時保護評論與管理員登入。
- 瀏覽器送出單次 `captchaToken`。
- 增加停服命令 `captcha status` / `captcha disable`。
- 管理端 CSP 按目前提供方收斂；Cap 需執行個體 Origin、WASM、Blob Worker。

遷移把 `turnstile_settings` 重新命名為 `captcha_settings`，保留開關與金鑰，預設 provider 為 Turnstile，再增加 Cap 欄位。

升級步驟見 [升級](../upgrade)。自 `v0.1.4`：改 tag 為 `v0.1.5`。若用 Cap，在 Cap Key 中允許管理端與全部評論站點 Origin。回滾必須還原停服前整庫備份；已寫入 v6 的庫不能只換回舊映像。
