# v0.6.2

- 發布日期：2026-11-23
- schema：v12（無遷移）
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.6.2`
- npm SDK：`ecoku@0.6.2`

## 變更 {#changes}

- 評論區預設樣式的回覆改為樹狀連線：第二至第四級回覆各由一個圓角轉角從父評論連到自己的作者列，後面還有同級回覆時豎線才繼續向下，最後一則回覆以轉角收尾。更深的回覆仍與第四級對齊，以「@暱稱」標明回覆對象。原先貫穿整串回覆的豎向引導線已移除。
- 新增 `--ecoku-thread-*` 變數，用於調整回覆縮排與連線，見 [自訂樣式](../../integration/custom-css#variables)。

## 相容性 {#compatibility}

- schema 維持 v12。從 v0.6.1 升級時，沿用現有資料與設定掛載、容器使用者和健康探針；設定項、介面與評論 DOM 結構不變。
- 只影響預設樣式 `ecoku.css`。使用 `ecoku.unstyled.css` 或 `data-css-url="none"` 的部落格，評論區外觀不變。
- 如果部落格的自訂樣式覆寫過回覆縮排，或為舊引導線（`.ecoku-comment-row::before`、`--ecoku-guide-offset`）寫過樣式，升級後請檢查評論區顯示。
- 從 v0.5.7 或更早版本升級時，先閱讀 [distroless 遷移說明](../upgrade#distroless)，同步更換舊 Compose 探針。

## 升級 {#upgrade}

按 [升級步驟](../upgrade#steps) 停止服務並冷備份，將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.6.2`，再拉取並重建容器。確認狀態為 `healthy`，檢查後台登入、已發布評論和新評論送出。透過 npm 引入 SDK 的網站，將相依套件改為 `ecoku@0.6.2`。

## 回滾 {#rollback}

停止服務，將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.6.1`，再拉取並重建容器。兩個版本皆使用 schema v12，保留現有資料庫與健康探針即可。
