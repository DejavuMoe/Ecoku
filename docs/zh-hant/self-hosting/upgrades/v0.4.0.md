# v0.4.0

- 發布日期：2026-10-09
- schema：v12（無遷移）
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.4.0`
- npm SDK：`ecoku@0.4.0`

## 變更 {#changes}

- 管理後台由 Vue 遷移至 Svelte 5，保留現有版面、功能與簡體中文、繁體中文、英語介面。
- 評論區 SDK 繼續使用無框架 TypeScript，本次依統一版本號發布；執行階段程式碼與 v0.3.8 相同。

## 相容性 {#compatibility}

- 沒有資料庫遷移，schema 仍為 v12。現有評論、站點、管理員帳戶和設定繼續保留。
- 管理位址、HTTP 介面、工作階段、設定鍵、環境變數、Compose 掛載和容器連接埠不變，容器部署不必額外安裝 Node.js 或啟動前端服務。
- 既有網站的接入程式碼不必修改，獨立安裝的 `ecoku@0.3.8` 可繼續使用。透過伺服器載入器接入的網站，SDK 隨容器映像檔更新。

## 升級 {#upgrade}

按 [升級步驟](../upgrade#steps) 停服並冷備份，將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.4.0`，拉取並啟動。

檢查容器健康狀態、啟動日誌、評論載入和後台登入，再確認站點與通知設定可以正常開啟。如果瀏覽器仍顯示舊後台，重新整理頁面以載入資源。獨立安裝的 SDK 可在 npm 發布成功後固定到 `ecoku@0.4.0` 並重新建置網站。

## 回滾 {#rollback}

從 v0.3.8 升級的實例，停服後將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.3.8`，拉取並啟動即可恢復 Vue 後台。schema 相同，不必還原資料庫，升級後的評論與設定會保留。獨立安裝的 SDK 可固定回 `ecoku@0.3.8` 後重新建置網站。

若從更早版本升級，先核對該版本的 schema 與對應版本的回滾說明。
