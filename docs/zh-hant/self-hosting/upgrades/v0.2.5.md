# v0.2.5

- 發布日期：2026-09-26
- schema：v8，無遷移
- 映像檔：`git.via.moe/dejavu/ecoku:v0.2.5`

## 變更

- 評論區預設樣式改為「紙與墨」：身分欄位為橫線式填寫欄，內文直接寫在發表卡片上；只保留一個實心主按鈕，貼圖、預覽、取消與排序改為文字按鈕；圓角 6px / 3px；時間、摺疊按鈕、字數和頁碼使用等寬字型；部落客標誌、連結滑過和表單錯誤使用朱砂色。Cap 元件維持官方的 260×58px 尺寸，外框圓角跟隨 Ecoku 變數。
- 預設的 `--ecoku-*` 變數改為零權重宣告，在 `.ecoku-comments` 上寫入同名變數即可覆寫，不再需要提高選擇器權重。新增強調色、錯誤色、圓角、陰影、等寬字型和字級變數，見[自訂樣式](../../integration/custom-css)。
- `data-theme="auto"` 不再固定 `color-scheme`，改為繼承頁面。部落格手動切換明暗、與系統設定不一致時，評論區不再出現反色。
- 觸控裝置上的輸入框字級不小於 16px，避免 iOS 在聚焦時放大頁面。
- Turnstile 伺服器端核驗收到 HTTP 重新導向時，視為驗證服務無法使用，請求會被拒絕。

## 相容性

設定項目、環境變數、Compose 掛載和密碼雜湊都沒有變化，可以從 v0.2.4 原地升級。評論區的 DOM 類別名稱、文案，以及 SDK 與載入器的介面都不變。

需要注意外觀上的變化：

- 使用預設注入樣式或 `/client/ecoku.css` 的站點，評論區外觀會隨映像檔更新。你原有的覆寫 CSS 可能與新的預設值疊加，升級後請在淺色和深色模式下各看一遍。以前為了壓過預設樣式而寫的高權重規則，可以改成在 `.ecoku-comments` 上宣告變數。
- `data-css-url` 指向自己的樣式表或設為 `none` 的站點，外觀不變。
- `/client/` 下的檔案會快取一小時，升級後部分訪客可能在短時間內仍看到舊樣式。

## 升級

依照[升級步驟](../upgrade#steps)操作，映像檔改為 `git.via.moe/dejavu/ecoku:v0.2.5`。啟動後開啟幾篇文章，在淺色和深色模式下檢查評論區、回覆框與驗證元件。

## 回滾到 v0.2.4

兩個版本都是 schema v8。停止服務，把映像檔改回 `git.via.moe/dejavu/ecoku:v0.2.4`，拉取並啟動即可，現有的資料庫和升級後的新評論都會保留。樣式和 Turnstile 重新導向的修正也會隨之回退。
