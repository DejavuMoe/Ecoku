# v0.2.5 升級說明

停服冷備份並驗證 → 改精確鏡像 tag → `sudo docker compose pull && sudo docker compose up -d` → 健康檢查與回滾。

發佈日期：2026-09-26。

評論區預設樣式改為「紙與墨」，預設 `--ecoku-*` 變數可由宿主直接覆蓋，`data-theme="auto"` 跟隨宿主明暗；Turnstile 伺服器端驗證拒絕 HTTP 重新導向。

## 主要變更

- 評論區預設樣式：身分欄位為橫線填寫欄，正文直接寫在發表卡片上；只保留一個實心主按鈕，表情、預覽、取消與排序為文字按鈕；圓角 6px / 3px；時間、折疊、字數與頁碼使用等寬字型；部落客標誌、連結懸停與表單錯誤使用朱砂強調色。Cap 保留官方 260×58px 幾何，外框圓角跟隨 Ecoku 變數。
- 預設 `--ecoku-*` 變數以零優先級宣告，在 `.ecoku-comments` 上寫同名變數即可覆蓋；新增強調色、錯誤色、圓角、陰影、等寬字型與字級變數，見[自訂 CSS](../../integration/custom-css)。
- `data-theme="auto"` 不再固定 `color-scheme`，站點手動切換明暗且與系統設定不一致時，評論區不再反色。
- 觸控裝置上的評論輸入框不小於 16px，避免 iOS 聚焦時放大頁面。
- Turnstile Siteverify 收到 HTTP 重新導向時按驗證服務不可用處理，繼續失敗關閉。

## 升級相容性

schema 維持 v8，不新增遷移；設定鍵、環境變數、Compose 掛載與密碼雜湊不變，v0.2.4 可原位升級。評論區 DOM 類別名稱、文案以及 SDK 與載入器介面不變。

接入站點請留意：

- 使用預設注入樣式或 `/client/ecoku.css` 的站點，評論區外觀隨鏡像更新。既有覆蓋 CSS 可能與新預設值疊加，升級後請在淺色與深色下檢查評論區；原先為壓過預設樣式而寫的高優先級規則，可以改成在 `.ecoku-comments` 上宣告變數。
- `data-css-url` 指向自行託管的樣式或設為 `none` 的站點，外觀不變。
- `/client/` 資源快取一小時，升級後瀏覽器可能短時間內仍使用舊樣式。

## 升級步驟

1. 依 [備份與恢復](../backup) 停服並製作卷外冷備份，校驗封存檔；包含 `data/`（含 WAL/SHM）、`app/config.yaml`、`ecoku.env` 與原 `compose.yaml`。
2. 將 Compose image 改為 `git.via.moe/dejavu/ecoku:v0.2.5`，執行以下命令。

```bash
sudo docker compose config --quiet
sudo docker compose pull && sudo docker compose up -d
sudo docker compose ps
sudo docker compose logs --tail=100 ecoku
curl --fail --silent --show-error http://127.0.0.1:12123/api/health
```

3. 開啟接入站點的文章頁，在淺色與深色下確認評論區、回覆框與驗證元件顯示正常。

## 回滾到 v0.2.4

兩版均為 schema v8。通常可停服後把鏡像改回 `git.via.moe/dejavu/ecoku:v0.2.4`，拉取並啟動，保留現有資料庫與升級後的新留言；評論區樣式與 Turnstile 重新導向修復隨之回退。只有確需恢復升級前資料時才使用整套冷備份：先保留當前現場，並明確接受備份後寫入的遺失，不要自動覆蓋資料庫。
