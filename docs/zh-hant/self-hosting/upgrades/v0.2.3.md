# v0.2.3

- 發布日期：2026-09-16（Git tag）
- schema：v7，無遷移
- 映像檔：`git.via.moe/dejavu/ecoku:v0.2.3`

## 變更

- 儲存站點設定時不再重新授予歷史評論部落客身分。部落客口令增加「UTF-8 編碼不超過 72 位元組」的檢查，已設定的口令繼續有效。
- SMTP 寄送的整個過程都可以取消，並受 20 秒逾時限制。通知寄出後如果寫回狀態失敗，只重試寫回，不重複寄送。Telegram 訊息保留完整的連結和 HTML 結構。
- Twikoo 匯入在記錄順序錯亂時也能正確還原父子關係。
- 評論和後台輸入支援完整的 Unicode 字元；後台請求的取消與逾時處理、載入器重試、Smoji 網址與鍵盤操作等多項修正。
- SDK 的 `setPageKey(pageKey, pageTitle)` 可以同時更新文章標題；省略第二個參數會清空舊標題。

## 相容性

掛載、環境變數和密碼雜湊格式不變，可以從 v0.2.2 原地升級。不會清理評論、設定、WAL 檔案或備份。

- 既有的部落客標記維持不變。舊版本在儲存站點時可能誤標過一些評論，這些記錄無法與真正以口令發布的評論自動區分，本版本不會批次修改。如果發現誤標，需要個別核實後處理。
- 通知以「至少一次」的方式投遞：程式在寄出通知後、記錄結果前當掉，重新啟動後可能會重複寄送一次。

## 升級

依照[升級步驟](../upgrade#steps)操作，映像檔改為 `git.via.moe/dejavu/ecoku:v0.2.3`。啟動後確認能登入後台、歷史評論和部落客標誌顯示正常。如需驗證通知，請手動寄送測試郵件或測試訊息。

## 回滾到 v0.2.2

兩個版本都是 schema v7。停止服務，把映像檔改回 `git.via.moe/dejavu/ecoku:v0.2.2`，拉取並啟動，現有的資料庫和新評論都會保留。本版修正的問題也會隨之重新出現。
