# v0.1.3

2026-08-15。Schema **v4 → v5**。

## 變更

- 部落客改為口令證明：公開區只在暱稱欄填口令。
- 通知按入隊時每個收件人拆成 outbox 行；worker 啟動收回全部 `processing` 行。
- SMTP 只允許 TLS / STARTTLS。
- management key 對評論 GET 列表/詳情回傳 403，只保留所屬站點墓碑刪除。
- 禁止 `trusted_proxies` 為 `0.0.0.0/0` 或 `::/0`。

遷移增加部落客口令雜湊、`comments.is_blogger`、outbox `target`。啟動後在管理端設定口令，會回填歷史部落客評論。

升級步驟見 [升級](../upgrade)。自 `v0.1.2`：改 tag 為 `v0.1.3`。回滾必須換回 `v0.1.2` **並** 用停服前整庫備份還原；已寫入 v5 的庫不能跑在 `v0.1.2` 上。
