# v0.1.3

2026-08-15。Schema **v4 → v5**。

## 變更

博主改為口令證明：公開區只在暱稱欄填口令。通知按入隊時每個收件人拆成 outbox 行；worker 啟動收回全部 `processing` 行。SMTP 只允許 TLS/STARTTLS。

management key 對評論 GET 列表/詳情返回 403，只保留所屬站點墓碑刪除。禁止 `trusted_proxies` 為 `0.0.0.0/0` 或 `::/0`。

## 升級

遷移增加博主口令哈希、`comments.is_blogger`、outbox `target`。

從 `v0.1.2`：停服冷備份（主庫 + 確認無 WAL/SHM）→ 鏡像 `v0.1.3` → `pull && up -d`。啟動後在管理端設定口令，歷史博主評論會被回填。

回滾必須換回 `v0.1.2` **並** 用停服前備份整庫恢復。已寫入 v5 的庫不能跑在 `v0.1.2` 上。
