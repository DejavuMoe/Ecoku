# v0.1.3

- 發布日期：2026-08-15
- schema：v4 → v5
- 映像檔：`git.via.moe/dejavu/ecoku:v0.1.3`

## 變更

- 部落客改為口令驗證：在評論區暱稱欄填寫口令，即以部落客身分發布。
- 通知在加入佇列時依收件者拆成多筆記錄，逐筆重試；通知程序啟動時回收所有「處理中」的記錄。
- SMTP 只允許 TLS 或 STARTTLS。
- 站點管理金鑰不能再讀取評論清單和詳細資訊（回傳 `403`），只保留對本站評論的墓碑刪除。
- `trusted_proxies` 禁止填寫 `0.0.0.0/0` 或 `::/0`。

## 相容性

schema v5 增加部落客口令雜湊、評論的部落客標記，以及通知佇列的收件目標欄位。在 v0.1.3 中，為站點設定部落客口令時，會依部落客暱稱和信箱回填歷史評論的部落客標記。

升級後需要在後台為站點設定部落客口令，才能繼續以部落客身分發言。

## 升級

1. 依照[備份與還原](../backup#cold-backup)停止服務並做冷備份。
2. 依照[升級步驟](../upgrade#steps)操作，映像檔改為 `git.via.moe/dejavu/ecoku:v0.1.3`。
3. 登入後台，為需要的站點設定部落客口令。

## 回滾

資料庫遷移到 v5 後，v0.1.2 無法開啟。回滾需要把映像檔改回 `v0.1.2`，並用升級前的冷備份[還原](../backup#restore)。
