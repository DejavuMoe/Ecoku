# v0.1.7

2026-08-26。Schema 仍為 v6。

## 變更

本版本更新本機開發、CI、容器建置工具鏈，以及文件站的建置/發佈流程。工具鏈固定為 Node.js 24.19.0、Go 1.27.0、pnpm 11.24.0；執行時鏡像仍為 Alpine 3.24.1。應用程式執行時契約沒有改變。

## 升級

本版本不新增環境變量、設定鍵或 Compose 掛載。容器仍以 UID/GID `10001:10001` 執行，`/data`、配置與日誌掛載路徑保持不變，因此現有 `v0.1.6` 實例不需要調整權限。

不要整體覆蓋現有 Compose 檔案；保留現有資源限制與掛載，只把精確鏡像 tag 改為 `git.via.moe/dejavu/ecoku:v0.1.7`。舊檔案沒有 `logging` 段時，按目前倉庫補上。

從 `v0.1.6` 升級：

1. 停止服務並冷備份 `data/`、`app/config.yaml`、`app/logs/`、`ecoku.env` 與目前的 Compose 檔案。
2. 修改精確鏡像 tag 為 `v0.1.7`。
3. 執行：

```bash
sudo docker compose config --quiet
sudo docker compose pull
sudo docker compose up -d
sudo docker compose ps
sudo docker compose logs --tail=200 ecoku
curl --fail http://127.0.0.1:12123/api/health
```

回滾時改回 `v0.1.6`。兩版同為 schema v6，一般不必替換資料庫；若啟動或驗證異常，仍使用停服前備份恢復。
