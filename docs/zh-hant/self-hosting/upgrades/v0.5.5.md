# v0.5.5

本版映像檔未通過發布門檻，沒有可供部署的正式映像檔。請使用 [v0.5.6](./v0.5.6)。

- 發布日期：2026-11-09
- schema：v12（無遷移）
- 映像檔：未發布
- npm SDK：`ecoku@0.5.5`

## 變更 {#changes}

- 更新 `golang.org/x/net` 至 v0.62.0，修復 Twikoo 匯入解析 HTML 時可能出現的二次複雜度漏洞（GO-2026-6860）。
- 更新 Happy DOM、文件開發伺服器 Vite 與 SDK 清理工具 rimraf 等建置和測試相依套件至修復版本。
- 整理通知佇列、管理後台工作階段與 SDK 載入器的內部狀態，對外行為不變。

## 相容性 {#compatibility}

- 沒有資料庫遷移，schema 仍為 v12。HTTP 介面、設定鍵、環境變數、Compose 掛載與容器連接埠不變。
- 映像檔掃描發現執行時基礎系統的 musl 與 zlib 存在高風險漏洞，映像檔未推送版本 tag，`ghcr.io/dejavumoe/ecoku:v0.5.5` 無法拉取。
- npm 上的 `ecoku@0.5.5` 對外行為與 `ecoku@0.5.4` 相同，可搭配 v0.5.4 伺服器使用；已固定 `ecoku@0.5.4` 的網站不必變更。

## 升級 {#upgrade}

本版不提供映像檔升級入口。從 v0.5.4 或更早版本升級時，請依 [v0.5.6 升級說明](./v0.5.6#upgrade) 操作。

## 回滾 {#rollback}

本版沒有正式發布的容器映像檔。現有實例可繼續執行已部署版本，升級與回滾以 [v0.5.6 說明](./v0.5.6#rollback) 為準。
