# v0.2.1

::: warning 內測版本，請勿使用
僅保留版本標籤、變更和歷史升級事項。公開部署從 v0.3.0 開始；舊映像檔不再提供部署支援。請使用 [目前部署文件](../docker)。
:::

- 發布日期：2026-09-12
- schema：v7，無遷移
- Git tag: [v0.2.1](https://github.com/DejavuMoe/Ecoku/tree/v0.2.1)

## 變更

- Smoji 清單容量提高到 64 個分組、每組 600 項、總計 6000 項，檔案上限 1 MiB（以 UTF-8 位元組計）。8 秒逾時涵蓋完整下載；增加 JSON 型別、標籤控制字元和圖片網址的檢查。
- 清單新增選用的 `base` 網址範本，項目可以省略重複的 `src`。舊格式繼續支援，見 [Smoji 貼圖包](../../integration/smoji#base)。

## 相容性

設定、環境變數和掛載不變，可以從 v0.2.0 原地升級。舊清單不需要修改。

使用 `base` 範本的清單在 v0.2.0 上無法解析。如果需要回滾，請保留一份逐項寫明 `src`、且不超出 v0.2.0 容量（32 組、每組 300 項、總計 2000 項、256 KiB）的清單。

## 歷史升級事項 {#upgrade}

本版本僅作歷史記錄，不提供安裝或降級步驟。跨 schema 還原需要與目標版本相符的完整冷備份；不能只切換映像檔。
