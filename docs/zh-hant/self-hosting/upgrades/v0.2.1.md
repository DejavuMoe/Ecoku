# v0.2.1

停服冷備份 → 修改精確鏡像 tag → `sudo docker compose pull && sudo docker compose up -d` → 健康與業務檢查。

## 升級影響

- SQLite 維持 **schema v7**，沒有資料庫遷移。
- 環境變數、Compose 掛載、連接埠與容器權限不變。
- Smoji 上限調整為 64 包、每包 600 項、共 6000 項與 1 MiB UTF-8；新增可選 `base` 模板。舊清單仍相容。

## 升級操作

1. 停服並備份 `data/`、`app/config.yaml`、`ecoku.env` 與原有 `compose.yaml`。
2. 將鏡像改為 `git.via.moe/dejavu/ecoku:v0.2.1`。
3. 執行 `sudo docker compose config --quiet && sudo docker compose pull && sudo docker compose up -d`，再檢查日誌、健康介面與評論區。

## 回滾至 v0.2.0

停服後恢復精確 `v0.2.0` 鏡像 tag，拉取並啟動。兩版均為 schema v7，通常無需恢復資料庫。
