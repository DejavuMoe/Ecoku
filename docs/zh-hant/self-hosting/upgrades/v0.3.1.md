# v0.3.1

- 發布日期：2026-10-03
- schema：v11 → v12
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.3.1`
- npm SDK：`ecoku@0.3.1`

## 變更 {#changes}

- 後台與評論區新增簡體中文、繁體中文和英語。後台透過 `ECOKU_ADMIN_LOCALE` 選擇語言；站點儲存評論區預設語言，SDK 的 `i18n` 參數優先覆寫站點設定。
- 文件移除日語，保留三語；首頁根據瀏覽器語言選擇入口，無法辨識時使用英語。Demo 評論區跟隨文件手動明暗切換。
- 取消切換文章和評論分頁的成功提示，保留分頁頁碼播報、發布成功與錯誤回饋。郵件品牌與排版對齊後台。

## 相容性 {#compatibility}

- 在 `sites` 資料表新增 `i18n_locale`，既有站點預設為 `zh-CN`。保留既有評論、帳戶、金鑰和通知設定，無需重新初始化。
- 後台語言預設為 `zh-CN`；可選 `zh-Hant`、`en`。既有 Compose 不新增此變數也可升級。
- 評論區語言優先順序：SDK `i18n` → 站點設定 → `zh-CN`。自訂文案保持原文。
- schema 不提供向下遷移，v0.3.0 無法開啟已升級到 v12 的資料庫。

## 升級 {#upgrade}

1. 停服並 [冷備份](../backup#cold-backup) 資料庫、`ecoku-secrets.json`、Compose 和設定檔。
2. 按 [升級步驟](../upgrade#steps) 將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.3.1`，執行 `sudo docker compose pull && sudo docker compose up -d`。
3. 檢查容器健康狀態、管理員登入、歷史評論、站點與通知設定；確認 schema v12 遷移成功。
4. npm 發布成功後，使用 `pnpm add --save-exact ecoku@0.3.1` 更新獨立接入的 SDK 並重新建置網站。容器內建 SDK 隨映像檔更新。

## 回滾 {#rollback}

停服後將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.3.0`，按 [還原說明](../backup#restore) 還原升級前同一份資料庫與持久金鑰備份，再啟動並檢查。不能只改映像檔 tag；備份之後新增的評論和設定修改會遺失。
