# v0.6.4

- 發布日期：2026-11-26
- schema：v12（無遷移）
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.6.4`
- npm SDK：`ecoku@0.6.4`

## 變更 {#changes}

- 管理後台評論頁在「已發布 / 已刪除」右側新增搜尋框，可在目前站點、目前一欄內依暱稱、信箱、訪客網站、內文、文章標題、頁面 key 或 `#編號` 查找，多個詞須全部符合，符合的詞以底色標出。用法見 [搜尋評論](../../admin/comments#search)。
- 後台評論清單介面 `GET /api/admin/sites/:siteId/comments` 新增 `q` 參數；帶 `q` 時計數與分頁只統計符合的評論，見 [HTTP 介面](../../reference/api)。

## 相容性 {#compatibility}

- schema 維持 v12。從 v0.6.3 升級時，沿用現有資料與設定掛載、容器使用者和健康探針；設定項不變。
- 已刪除的評論只保留文章標題、頁面 key 和編號，搜尋時只依這三項比對。
- 搜尋詞只隨請求送出，不寫入頁面網址或瀏覽器儲存空間；存取日誌只記錄路由範本，不記錄搜尋詞。
- npm SDK `ecoku@0.6.4` 的執行階段程式碼與 0.6.3 相同。
- 從 v0.5.7 或更早版本升級時，先閱讀 [distroless 遷移說明](../upgrade#distroless)，同步更換舊 Compose 探針。

## 升級 {#upgrade}

按 [升級步驟](../upgrade#steps) 停止服務並冷備份，將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.6.4`，再拉取並重建容器。確認狀態為 `healthy`，登入後台查看底部版本號為 `v0.6.4`，在評論頁搜尋一則已知評論的暱稱或內文，確認能找到並標出符合的詞。透過 npm 引入 SDK 的網站，將相依套件改為 `ecoku@0.6.4`。

## 回滾 {#rollback}

停止服務，將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.6.3`，再拉取並重建容器。兩個版本皆使用 schema v12，保留現有資料庫與健康探針即可。
