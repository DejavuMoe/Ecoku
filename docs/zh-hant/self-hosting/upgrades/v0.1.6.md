# v0.1.6

2026-08-18。Schema 仍為 v6。

## 變更

啟用 Cap instrumentation 時，管理端僅在 Cap 為目前方式時額外開放 `script-src 'unsafe-eval'`。關閉或切回 Turnstile 後收回該放寬。`'wasm-unsafe-eval'` 不能代替 JavaScript `'unsafe-eval'`。不接受時關閉 instrumentation 或改用 Turnstile。

升級步驟見 [升級](../upgrade)。自 `v0.1.5`：改 tag 為 `v0.1.6`。無新環境變數或掛載。回滾 `v0.1.5`（同 schema，一般不必換庫）。
