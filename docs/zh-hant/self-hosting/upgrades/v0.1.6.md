# v0.1.6

2026-08-18。Schema 仍為 v6。

## 變更

啟用 Cap instrumentation 後，當前 Cap 3.x 生成的腳本會調用 `eval` / `new Function`。管理端僅在 Cap 為當前方式時，為其精確 Origin、WASM、Blob Worker 和 nonce 額外開放 `script-src 'unsafe-eval'`。關閉或切回 Turnstile 後不再放寬 CSP。

`'wasm-unsafe-eval'` 只允許 WebAssembly，不能代替 JavaScript `'unsafe-eval'`。不接受該權衡時，關閉該 Cap Key 的 instrumentation 或改用 Turnstile。

## 升級

無新環境變量或掛載。從 `v0.1.5`：

1. 停服冷備份
2. `compose.yaml` 鏡像改為 `v0.1.6`
3. `sudo docker compose pull && sudo docker compose up -d`

若曾為恢復登入而關閉 instrumentation，升級後先確認管理端 CSP 只在 Cap 模式包含 `'unsafe-eval'`，再重新開啟，並分別驗證登入與評論送出。

回滾改回 `v0.1.5`。兩版同為 schema v6，一般不必換庫；啟動異常仍用停服前備份。
