# v0.1.8

2026-08-27。站點可選啟用 Smoji 表情包並設定一個遠端 v1 清單 URL。選擇器按需載入清單；表情資源不會打包進 Ecoku 映像。生產清單 URL 必須使用 HTTPS，圖片必須與清單同源。

Schema 由 v6 原位、按事務升級至 v7，為 `sites` 增加 `smoji_enabled` 與 `smoji_manifest_url`。既有站點預設關閉且清單為空。不新增環境變數、設定鍵、Compose 掛載或容器權限要求。

請依 [升級](../upgrade) 操作。自 `v0.1.7` 升級：停服冷備份，把 Compose 改為精確 tag `v0.1.8`，執行 `sudo docker compose config --quiet`、`sudo docker compose pull`、`sudo docker compose up -d`，再檢查日誌、`docker compose ps`、`/api/health`、評論與管理端。啟動時會自動執行 v6 → v7 遷移。

回滾不能只把 tag 改回 `v0.1.7`。若新版本已寫入 v7，必須停服並還原升級前的整庫備份，再用 `v0.1.7` 啟動。
