# v0.1.8

- 發布日期：2026-08-27
- schema：v6 → v7
- 映像檔：`git.via.moe/dejavu/ecoku:v0.1.8`

## 變更

- 站點可以啟用 Smoji 貼圖包，並填寫一個遠端 v1 清單網址。訪客第一次開啟貼圖選擇器時才載入清單；貼圖圖片不會打包進 Ecoku 映像檔。
- 正式環境的清單網址必須是 HTTPS，貼圖圖片必須與清單同源。
- 選取的貼圖以 `![smoji:名稱](完整圖片網址)` 的純文字形式保存。關閉功能後，歷史標記依原文顯示。

## 相容性

schema v7 為站點資料表增加 Smoji 開關和清單網址兩個欄位，既有站點預設為關閉。沒有新的環境變數、設定項目、掛載或權限要求。

## 升級

1. 依照[備份與還原](../backup#cold-backup)停止服務並做冷備份。
2. 依照[升級步驟](../upgrade#steps)操作，映像檔改為 `git.via.moe/dejavu/ecoku:v0.1.8`。啟動時會自動遷移到 v7。
3. 檢查評論區和管理後台。

## 回滾

資料庫遷移到 v7 後，v0.1.7 無法開啟。回滾需要停止服務，用升級前的冷備份[還原](../backup#restore)，再以 v0.1.7 啟動。備份之後的新資料會遺失。
