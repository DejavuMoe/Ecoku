# v0.5.3

- 發布日期：2026-10-19
- schema：v12（無遷移）
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.5.3`
- npm SDK：`ecoku@0.5.3`

## 變更 {#changes}

- 管理後台介面打磨，功能不變：桌面頂欄導覽置中；評論按「2026 年 10 月 18 日」分組，不再顯示星期，英文後台顯示為 October 18, 2026。刪除確認改為評論下方的卡片，可按 Esc 取消；人機驗證方式改為三張並排的選擇卡；逐項列表的刪除按鈕移入輸入框。
- 英文與繁體中文後台的評論分頁按鈕不再顯示簡體中文。
- 更新測試與文件建置依賴，修復已知依賴漏洞；三語維運、接入與首次登入文件依原始碼校正。

## 相容性 {#compatibility}

- 沒有新增資料庫遷移，schema 仍為 v12。API、設定鍵、環境變數、Compose 掛載與容器連接埠不變。
- 伺服器與 SDK 執行時程式碼與 v0.5.2 相同，既有接入保持相容。後台的變化只在介面上，管理員帳戶、工作階段和設定不受影響。
- 從早於 v0.5.2 的版本升級時，另讀 [v0.5.2 的首次登入說明](./v0.5.2#compatibility)；早於 v0.5.0 時，再讀 [來源衝突與歷史資料說明](./v0.5.0#compatibility)。

## 升級 {#upgrade}

依 [升級步驟](../upgrade#steps) 停服並冷備份，將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.5.3`，依通用步驟拉取映像檔、重建容器並等待健康。

檢查容器健康狀態、啟動日誌、評論載入與提交、後台登入。每個實例都要單獨升級，包括為文件範例提供服務的實例。獨立安裝的 SDK 可在 npm 發布成功後固定到 `ecoku@0.5.3` 並重新建置網站。

## 回滾 {#rollback}

從 v0.5.2 升級的實例，停服後將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.5.2`，拉取並啟動。schema 相同，無需還原資料庫，升級後的評論和設定會保留。SDK 可固定回 `ecoku@0.5.2` 後重新建置網站。從更早版本升級的實例須核對對應 schema 和回滾說明。
