# v0.4.1

- 發布日期：2026-10-09
- schema：v12（無遷移）
- 映像檔：`ghcr.io/dejavumoe/ecoku:v0.4.1`
- npm SDK：`ecoku@0.4.1`

## 變更 {#changes}

- 移除後台全局快捷鍵及提示，包括評論導覽、檢視原評論、刪除確認、重新整理和儲存設定的快捷鍵。繼續使用頁面上的對應按鈕；表單、選單和按鈕的基本鍵盤操作保留。
- npm 套件首頁的安裝範例同步至 `ecoku@0.4.1`，補齊 SDK 套件內更新日誌，並加入發布一致性校驗。

## 相容性 {#compatibility}

- 沒有資料庫遷移，schema 仍為 v12。管理位址、HTTP 介面、工作階段、設定鍵、環境變數、Compose 掛載和容器連接埠不變。
- 現有評論、站點、管理員帳戶和設定繼續保留。刪除確認與離開未儲存設定時的提醒仍透過原有介面完成。
- 評論區 SDK 繼續使用無框架 TypeScript，執行階段程式碼與 v0.4.0 相同；既有接入程式碼不必修改，獨立安裝的 `ecoku@0.4.0` 可繼續使用。

## 升級 {#upgrade}

按 [升級步驟](../upgrade#steps) 停服並冷備份，將映像檔改為 `ghcr.io/dejavumoe/ecoku:v0.4.1`，拉取並啟動。

檢查容器健康狀態、啟動日誌、評論載入和後台登入；重新整理後台頁面，確認快捷鍵提示已移除，清單與設定按鈕正常顯示。容器內建 SDK 隨映像檔更新；獨立安裝的 SDK 可在 npm 發布成功後固定到 `ecoku@0.4.1` 並重新建置網站。

## 回滾 {#rollback}

從 v0.4.0 升級的實例，停服後將映像檔改回 `ghcr.io/dejavumoe/ecoku:v0.4.0`，拉取並啟動即可。schema 相同，不必還原資料庫，升級後的評論與設定會保留；舊版的後台快捷鍵及提示也會恢復。獨立安裝的 SDK 可固定回 `ecoku@0.4.0` 後重新建置網站。

若從更早版本升級，先核對該版本的 schema 與對應版本的回滾說明。
