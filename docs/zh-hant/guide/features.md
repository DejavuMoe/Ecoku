# 特性全覽

Ecoku 在保持極簡架構的同時，提供了完善的評論互動、現代安全機制、優雅排版與靈活定製能力。

---

## 評論互動體驗
- **送出即時公開**：無任何前置人工審核阻塞，發表成功後即刻呈現在評論列表中。
- **無限語意與 3 級視覺縮排**：底層資料支援無限層級巢狀回覆；前端視覺採用智慧階梯縮排，最多縮排 3 級，深層回覆自動呈現 `@被回覆者` 可點選錨點。
- **根討論串分頁模型**：預算內按根評論批次回傳完整討論串，超限明確報錯，不靜默截斷；大型討論串可透過[單層游標 API](../reference/api.md)按需讀取。
- **等寬摺疊控制項**：摺疊控制項 `[+]` 與 `[-]` 固定為 `3ch` 等寬，切換時元資訊行零抖動。
- **墓碑式軟刪除**：刪除評論時保留結構墓碑，正文顯示為 `[該評論已刪除]`。
- **Smoji 純文字貼圖**：支援站點級自訂貼圖包，採用 `![smoji:標籤](url)` 純文字標記儲存。

## 身分認證與隱私保護
- **靈活欄位控制**：暱稱始終必填；私有信箱與個人網站由站點設定決定是否必填。
- **客戶端 AES-GCM 加密儲存**：訪客填寫的身分資訊透過 WebCrypto API 生成 256 位元金鑰加密存於 IndexedDB，7 天後自動靜默失效。
- **站長免密口令（Passphrase）**：站長只需在暱稱框輸入口令即可自動點亮站長徽章並完成身分認證。
- **嚴格零隱私洩漏**：公開 API DTO 嚴格剔除信箱、IP、User-Agent 等敏感資料。
