# 特性

## 評論

- 純文字，送出即公開。
- 多層討論串；視覺縮進最多三級。公開列表按根討論串分頁，當前頁包含這批根評論的全部公開後代。
- 回覆在被回複評論下方完成。缺少身份時就在該回覆框採集，不會誤發成根評論。
- 排序：站點預設「最新」或「最早」，訪客可臨時切換。
- 刪除後保留墓碑：固定暱稱「已刪除」、正文「[該評論已刪除]」，不可再回覆。

## 身份

- 暱稱始終必填。信箱、網站是否必填按站點配置，預設信箱必填、網站可選。
- 已填寫的身份用非導出 AES-GCM 金鑰加密，存入當前 Origin 的 IndexedDB，按 `serverURL + siteId` 隔離，7 天后失效。不寫 localStorage、cookie 或 URL，也沒有單獨的清除按鈕。
- 博主：管理端配置暱稱、信箱和口令。公開區只在暱稱欄填口令，服務端改寫為配置暱稱、私有信箱和站點 URL。徽章預設 `[博主]`，無頭像。

## 管理

- 單一實例管理員，入口 `/admin/`。Token 只在當前頁面記憶體，重新整理需重新登入。
- 站點 ID 建立後不可改。可配置允許來源、排序、欄位要求、提示文字、Unicode 上限（1–10000，預設 1000）和空狀態文案。
- 評論管理：按已發布 / 墓碑篩選、詳情、墓碑刪除；無後代墓碑可徹底刪除。
- 機器人驗證為實例級三態：關閉、Cloudflare Turnstile、自託管 Cap。啟用時同時保護評論送出和管理員登入；失敗則拒絕，不會自動降級。

## 通知

| 送出者 | 對象 | 結果 |
| --- | --- | --- |
| 訪客 | 根評論 | 博主 SMTP / Telegram |
| 訪客 | 訪客 | 博主渠道 + 被回覆者郵件 |
| 訪客 | 博主 | 博主渠道一次 |
| 博主 | 根評論 / 博主 | 不發送 |
| 博主 | 訪客 | 僅被回覆者郵件 |

同一信箱回覆自己不發訪客回覆郵件。SMTP 只允許 `tls` 或 `starttls`。密碼與 Bot Token 加密入庫，界面只顯示「已設定」。

## 資料與隱私

- 只使用 SQLite3。遷移按版本順序、在原檔案內事務執行；成功只追加版本記錄。
- 公共 DTO 不含信箱、IP、UA、地區或金鑰。IP 只在行程內短暫用於限流。
- 預設不信任 `X-Forwarded-For`。按人限流時只信任 Docker 網關，由反代覆蓋轉發頭。

## 接入

鏡像提供 `/client/ecoku-loader.js`、`/client/ecoku.umd.js`，以及 `/client/ecoku.css` 與結構用 `/client/ecoku.unstyled.css`。頁面必須顯式給出容器、`serverURL`、`siteId` 和站內相對路徑 `pageKey`。
