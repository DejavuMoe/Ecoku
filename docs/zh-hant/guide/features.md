# 特性全覽

Ecoku 在保持極簡架構的同時，提供了完善的評論互動、現代安全機制、優雅排版與靈活定製能力。

---

## 評論互動體驗
- **送出即時公開**：無任何前置人工審核阻塞，發表成功後即刻呈現在評論列表中。
- **16 層回覆與 3 級視覺縮排**：新回覆最多支援 16 層後代；前端視覺採用智慧階梯縮排，最多縮排 3 級，深層回覆自動呈現 `@被回覆者` 可點選錨點。
- **根討論串分頁模型**：預算內按根評論批次回傳完整討論串，超限明確報錯，不靜默截斷；大型討論串可透過[單層游標 API](../reference/api.md)按需讀取。
- **等寬摺疊控制項**：摺疊控制項 `[+]` 與 `[-]` 固定為 `3ch` 等寬，切換時元資訊行零抖動。
- **墓碑式軟刪除**：刪除評論時保留結構墓碑，正文顯示為 `[该评论已删除]`。
- **Smoji 純文字貼圖**：支援站點級自訂表情包，採用 `![smoji:標籤](https://...)` 純文字標記儲存，客戶端同源按需載入，安全無痕。

## 身分認證與隱私保護
- **靈活欄位控制**：暱稱始終必填；私有信箱與個人網站由站點設定決定是否必填（預設信箱必填、網站可選）。
- **客戶端 AES-GCM 加密儲存**：訪客填寫的身分資訊透過 WebCrypto API 生成 256 位元金鑰加密存於 IndexedDB，7 天後自動靜默失效，絕不落盤於 `localStorage` 或 Cookie。
- **站長免密口令（Passphrase）**：站長只需在暱稱框輸入口令即可自動點亮站長徽章並完成身分認證，無需在公共設備暴露私有信箱。
- **嚴格零隱私洩漏**：公開 API DTO 嚴格剔除信箱、IP、User-Agent、地理位置等敏感資料；日誌系統同樣絕不記錄隱私欄位。

## 現代化安全與人機防護

- **三態人機驗證切換**：實例級自由切換 **關閉 (`off`)**、**Cloudflare Turnstile** 或 **自託管 Cap**。
- **資料庫憑證加密**：資料庫內儲存的 Turnstile Secret、Cap Secret、SMTP 密碼及 Telegram Token 均由主金鑰採用 AES-256-GCM 強加密儲存，管理端僅顯示「已設定」，永不回顯明文。
- **動態 CSP 安全收斂**：管理端 Content-Security-Policy 隨當前驗證提供方動態收斂，僅在啟用 Cap 時精準放行其 HTTPS 實例網域與必要求值權限，其餘模式全面收緊。
- **多維度單處理程序限流**：內建基於 Socket 對端 IP 與可信反代閘道的記憶體限流器，對評論送出、刪除、管理登入與通知測試施加精準頻控。

## 維運與基礎設施

- **單容器極簡交付**：Go 單二進位一體化託管 API、管理後台與前端 SDK，依賴零膨脹。
- **SQLite3 WAL 模式**：高並發讀寫效能，原位順序版本化遷移（v1～v8），安全可靠。
- **Outbox 交易一致性通知**：評論寫入與通知入隊原子提交，支援 SMTP（TLS/STARTTLS）與 Telegram 機器人雙渠道，按目標拆行獨立重試。
- **Twikoo 零損遷移工具**：內建 CLI 工具，支援從 Twikoo 匯出資料平滑匯入，自動清洗轉換層級與 Markdown 標記，靜默無通知匯入。
- **雙主題與完整 Design Tokens**：評論區與管理端均原生支援深淺色自適應，提供全套 CSS 變數方便快速融入各類部落格設計。
