# 紹介

Ecoku はセルフホスト向けのマルチサイト純テキストコメントシステムです。1 インスタンスで複数サイトを扱えます。コメントは送信と同時に公開されます。

静的ブログやドキュメントサイト、コメントを第三者 SaaS に預けたくない個人サイト向けです。本番は Docker Compose と SQLite3 のみです。

## できること

- 訪問者コメント：ニックネーム必須。メールとウェブサイトの必須可否はサイトごと。
- 意味上は無制限の返信スレッド。公開一覧はルートスレッド単位でページ送り。
- 削除は墓碑を残し、子孫の返信は残ります。
- インスタンス管理者：サイト、コメント、通知、ボット対策。
- 同一オリジンのブラウザ SDK `/client/ecoku-loader.js`。
- 任意：SMTP / Telegram、初回 Twikoo 取り込み、Cloudflare Turnstile またはセルフホスト Cap。

## やらないこと

本文はプレーンテキストのみで、HTML も Markdown も解釈しません。アバター、評価、リッチテキスト、一般ユーザー登録、サイト別審査、MySQL はありません。

管理者トークンやサイト management key をブラウザ、URL、ページ markup に置かないでください。

## 実行形態

非 root のコンテナ 1 つが API、`/admin/`、コメントフロントを提供します。ポートはホストの `127.0.0.1:12123`。公開面はローカルの Caddy または Nginx です。

データはコンテナの外に置きます。

| パス | 用途 |
| --- | --- |
| `app/config.yaml` | 公開設定（ポート、ログ、信頼プロキシ、管理オリジン） |
| `ecoku.env` | 管理者資格情報、通知暗号化キー、タイムゾーン |
| `data/` | SQLite 本体と WAL |
| `app/logs/` | 任意のファイルログ |

サイト・フォーム・通知チャネルは管理画面から SQLite に書き込みます。YAML の `sites` は空 DB の初回だけ取り込みます。

## バージョン

コンテナ版はリポジトリ根の `VERSION` です。Git タグは `v` + その値。`compose.yaml` は正確なタグを使い、`latest` は使いません。
