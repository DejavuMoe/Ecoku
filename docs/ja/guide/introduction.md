# 紹介

Ecoku はセルフホストのマルチサイト純テキストコメントシステムです。1 インスタンスで複数サイトを扱い、投稿はすぐに公開されます。

静的ブログ、ドキュメントサイト、コメントデータを自分のサーバーに置きたい個人サイト向けです。本番は Docker Compose と SQLite3 を使います。

現在は Docker イメージのみ公開し、ソースコードは公開配布していません。

## 向いている用途

- 複数サイトにコメント欄を提供する。
- ニックネーム、メール、任意のウェブサイトでコメントと返信を受け付ける。
- 任意でメールまたは Telegram 通知。Twikoo から既存コメントを一度だけ取り込める。
- Cloudflare Turnstile またはセルフホストの Cap でボット対策できる。

## 提供しないもの

本文はプレーンテキストで、HTML と Markdown は解釈しません。アバター、評価、リッチテキスト、一般ユーザーアカウント、サイト別の審査キュー、MySQL は提供しません。

管理者資格情報やサイトの management key をブラウザ、URL、ページ markup に置かないでください。

## 動かし方

非 root のコンテナ 1 つが API、管理画面 `/admin/`、コメントフロントエンド `/client/` を提供します。既定ではホストの `127.0.0.1:12123` にだけ bind し、公開アクセスは HTTPS リバースプロキシに任せます。

サイト、フォーム、通知は管理画面で設定し、SQLite に保存します。初回導入は [Docker 導入](/ja/self-hosting/docker)、ページ組み込みは [汎用 HTML](/ja/integration/html) を参照してください。
