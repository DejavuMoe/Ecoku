# 機能一覧

Ecoku は最小限の構成でありながら、優れたコメント体験と堅牢なセキュリティを提供します。

---

## コメント体験
- **投稿後その場で公開**：審査キューによる待機なし。
- **最大16階層の返信と最大3段階のインデント**：新規返信は最大16階層。画面表示は最大3階層で折り返し、深層階層では `@返信先` リンクを自動表示。
- **ルートスレッド単位のページネーション**：処理上限内では完全なスレッドを返し、超過時は明示的に失敗します。大きなスレッドは[単一階層カーソル API](../reference/api.md)で必要な分だけ取得できます。
- **3ch 等幅の折りたたみボタン**：`[+]` と `[-]` を 3ch の等幅で描画し、切り替え時のレイアウトシフトを防止。
- **コンテキストを保持する墓標（Tombstone）**：削除されたコメントは `[该评论已删除]` と表示され、会話の文脈を維持。
- **Smoji 純テキストスタンプ**：サイトごとのカスタムスタンプパックに対応。`![smoji:ラベル](https://...)` の純テキストトークンとして保存され、クライアント側で同一オリジン検証の上オンデマンド読み込み。

## プライバシーと認証
- **柔軟な必須項目設定**：ニックネームは必須、メールアドレスとウェブサイトはサイトごとに任意/必須を設定可能（デフォルトはメール必須、サイト任意）。
- **クライアント側 AES-GCM 暗号化**：訪問者情報は WebCrypto API により 256 ビット鍵で暗号化され、IndexedDB に保存され、7 日後から復元対象外になります。`localStorage` や Cookie には一切書き込みません。
- **ブロガー合言葉認証**：ニックネーム欄に秘密の合言葉を入力するだけで、メールアドレスを公開せずブロガーとして認証され、専用バッジを表示。
- **個人情報の完全非公開**：公開 API はメール、IP、User-Agent、地域情報を返却しません。ログにも一切記録しません。

---

## 現代的なセキュリティとボット防御

- **3 状態のボット認証切り替え**：インスタンス全体で **無効 (`off`)**、**Cloudflare Turnstile**、**セルフホスト型 Cap** の 3 つから選択。
- **機密情報の完全暗号化**：Turnstile Secret、Cap Secret、SMTP パスワード、Telegram Token はマスター鍵を用いて AES-256-GCM で暗号化保存。管理画面でもマスクされ平文は漏洩しません。
- **動的 CSP ポリシー収束**：選択中の認証プロバイダーに応じて Content-Security-Policy を動的に最適化。Cap 有効時のみ必要なドメインと WASM 評価を許可し、それ以外では厳格に制限。
- **多次元インメモリレート制限**：Socket 対向 IP および信頼できるプロキシに基づくレート制限により、コメント投稿、削除、管理ログイン、通知テストを保護。

## 運用とインフラ

- **単一コンテナ極小デプロイ**：Go の単一バイナリが API、管理画面、フロントエンド SDK を一体提供。外部依存ゼロ。
- **SQLite3 WAL モード**：高い並行読み書き性能、インプレースな順次スキーママイグレーション（v1〜v8）。
- **Outbox トランザクショナル通知**：コメント保存と通知登録を同一トランザクションでコミット。SMTP（TLS/STARTTLS）と Telegram Bot に対応し、宛先ごとに独立して再試行。
- **Twikoo 完全移行ツール**：既存の Twikoo エクスポート JSON からデータを安全に取り込み、Markdown をクリーンなテキストに変換。通知を飛ばさず静かに移行。
- **デュアルテーマと Design Tokens**：コメント欄・管理画面ともにライト/ダークテーマに対応し、CSS 変数で自由にカスタマイズ可能。
