# 機能

## コメント

- プレーンテキスト。投稿はすぐに公開され、審査キューはありません。
- 返信は対象コメントの直下に書きます。データ層の入れ子に上限はなく、UI の字下げは最大 3 段です。
- ルートコメントはページ送りし、そのページのルートに属する公開返信をすべて含めます。
- 新しい順／古い順で並べ替えできます。
- 削除はプレースホルダ（墓碑）を残しスレッドを崩しません。墓碑には返信できません。
- Smoji ステッカーをサイトごとに有効化できます。選択画面は同一オリジンのマニフェストを必要時だけ読み込み、選択結果はプレーンテキストのマーカーで保存します。

## 身元とプライバシー

- ニックネーム必須。メールとウェブサイトの必須／任意はサイト設定（既定はメール必須・サイト任意）。
- 訪問者の身元はブラウザ IndexedDB に 7 日間暗号化保存し、localStorage・Cookie・URL には書きません。
- 公開 API はメール、IP、User-Agent、地域、秘密鍵を返しません。

## 管理と通知

- `/admin/` でサイト、コメント、ブロガー身元、通知、ボット対策を設定します。
- ブロガーはニックネームとメールの両方で一致し、バッジを表示できます。有効時はパスフレーズで身元を証明します。
- 通知は SMTP と Telegram に対応。ルールとチャネルは [管理画面](/ja/self-hosting/admin#通知) を参照。
- ボット対策はインスタンス単位でオフ／Turnstile／セルフホスト Cap。有効時はコメント投稿と管理者ログインの両方を保護します。

## データと組み込み

- SQLite のみ。マルチサイト。スキーマは順序どおりその場で移行します。
- 資産：`/client/ecoku-loader.js`、`/client/ecoku.umd.js`、`/client/ecoku.css`、`/client/ecoku.unstyled.css`。
- 組み込みにはサービス URL、サイト ID、安定した page key、任意のページタイトルが必要です。詳しくは [汎用 HTML](/ja/integration/html)。
