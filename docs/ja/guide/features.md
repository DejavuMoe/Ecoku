# 機能一覧

Ecoku は最小限の構成でありながら、優れたコメント体験と堅牢なセキュリティを提供します。

---

## コメント体験
- **投稿後その場で公開**：審査キューによる待機なし。
- **無制限の階層セマンティクスと最大3段階のインデント**：データは無制限にネスト可能。画面表示は最大3階層で折り返し、深層階層では `@返信先` リンクを自動表示。
- **ルートスレッド単位のページネーション**：処理上限内では完全なスレッドを返し、超過時は明示的に失敗します。大きなスレッドは[単一階層カーソル API](../reference/api.md)で必要な分だけ取得できます。
- **3ch 等幅の折りたたみボタン**：`[+]` と `[-]` を 3ch の等幅で描画し、切り替え時のレイアウトシフトを防止。
- **コンテキストを保持する墓標（Tombstone）**：削除されたコメントは `[このコメントは削除されました]` と表示され、会話の文脈を維持。
- **Smoji 純テキストスタンプ**：`![smoji:タグ](url)` のテキスト形式で保存し、クライアント側で安全に読み込み。

---

## プライバシーと認証
- **柔軟な必須項目設定**：ニックネームは必須、メールアドレスとウェブサイトはサイトごとに任意/必須を設定可能。
- **クライアント側 AES-GCM 暗号化**：訪問者情報は WebCrypto API により暗号化され、IndexedDB に 7 日間のみ保持。
- **ブロガー合言葉認証**：ニックネーム欄に秘密の合言葉を入力するだけで、メールアドレスを公開せずブロガーとして認証。
- **個人情報の完全非公開**：公開 API はメール、IP、UA を返却しません。
