# 機能

Ecoku の現行バージョン（v0.2.9）の機能を、利用者ごとに分けて紹介します。各項目の後のリンクから詳しい説明に移動できます。

## 訪問者

- 登録不要で、ニックネーム、メールアドレス、任意の URL を入力すれば投稿できます。メールアドレスと URL を必須にするかはサイトごとに決めます。[訪問者情報](./concepts#visitor-identity)
- どのコメントにも直接返信できます。返信欄はその場で開き、足りない訪問者情報は返信欄の中で入力します。
- ブラウザが訪問者情報を暗号化して 7 日間記憶します。Cookie は使いません。
- 投稿前にプレビューできます。文字数は Unicode 文字単位で数え、漢字 1 文字は 1 文字です。
- 新しい順と古い順の並び替えを切り替えられます。
- 長い議論の枝を折りたためます。
- サイトでスタンプパックが有効なら、Smoji スタンプを挿入できます。[Smoji スタンプパック](../integration/smoji)

## ブロガー

- コメント欄のニックネーム欄に合言葉を入力すると、ブロガーとして投稿され、ブロガーバッジが表示されます。[ブロガー](./concepts#blogger)
- 新しいコメントや返信をメールまたは Telegram で通知します。[通知](../self-hosting/notifications)
- 訪問者のコメントに返信が付くと、その訪問者に自動でメールが届きます。

## 管理者

- 1 つのインスタンスに複数のサイトを登録し、許可オリジン、デフォルトの並び順、必須項目、文字数上限、案内文をサイトごとに設定できます。[管理画面](../self-hosting/admin#sites)
- コメントを「公開中 / 削除済み」（已发布 / 已删除）で絞り込んで閲覧し、ワンクリックで元記事の該当位置に移動できます。
- 墓標削除は議論の構造を残します。返信のない墓標は完全削除できます。[削除](./concepts#deletion)
- CAPTCHA を無効、Cloudflare Turnstile、セルフホストの Cap の 3 つから選べ、コメント投稿と管理画面ログインの両方を保護します。[CAPTCHA](../self-hosting/captcha)
- Twikoo から過去のコメントをインポートできます。[Twikoo からの移行](../self-hosting/twikoo)

## 埋め込み

- HTML とスクリプト 1 つで埋め込め、どの静的サイトでも使えます。[HTML で埋め込む](../integration/html)
- Vue や React などのシングルページアプリで記事を切り替えると、コメント欄も切り替わります。[JavaScript SDK](../integration/sdk)
- Hugo PaperMod テーマ用のテンプレートを用意しています。[Hugo PaperMod](../integration/hugo)
- デフォルトのスタイルは CSS 変数で色、角丸、文字サイズを調整できます。構造スタイルだけを使うことも、すべて自分で書くこともできます。[カスタムスタイル](../integration/custom-css)
- ページのライトモードとダークモードに追従します。

## 運用

- Docker コンテナ 1 つで、非 root・読み取り専用ファイルシステムで動作します。[Docker デプロイ](../self-hosting/docker)
- データはすべて 1 つの SQLite ファイルに入り、停止してコピーすればバックアップできます。[バックアップと復元](../self-hosting/backup)
- アップグレード時はデータベースが自動でマイグレーションされ、既存のデータはそのまま残ります。[アップグレード](../self-hosting/upgrade)
- IP ごとのレート制限があり、リバースプロキシや CDN の背後にも置けます。[リバースプロキシ](../self-hosting/reverse-proxy)
- 通知はデータベースのキューを使って非同期に送信され、失敗すると自動で再試行します。コメントの投稿には影響しません。

## プライバシー

- 訪問者の IP、User-Agent、位置情報を保存しません。[保存・公開されるデータ](./concepts#data)
- メールアドレスはどの公開 API にも含まれません。
- SMTP パスワード、Bot Token、CAPTCHA のシークレットは暗号化してデータベースに保存され、管理画面には「設定済み」（已设置）とだけ表示されます。
- コメント欄はサードパーティーのアバター、アクセス解析、IP 検索サービスにリクエストしません。
