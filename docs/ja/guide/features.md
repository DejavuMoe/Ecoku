# 機能

## コメント

- プレーンテキスト。送信と同時に公開。
- 入れ子スレッド。見た目のインデントは 3 段まで。公開一覧はルートスレッド単位。そのページには当該ルートの公開子孫がすべて含まれます。
- 返信は親コメントの直下で入力。身元が無い場合もその返信欄で集め、ルート投稿に誤送信しません。
- 並び：サイト既定は `newest` または `oldest`。訪問者は一時的に切り替え可能。
- 墓碑はニックネーム「已删除」、本文「[该评论已删除]」。新規返信は不可。

## 身元

- ニックネームは常に必須。メールとサイトの必須はサイト設定（既定はメール必須、サイト任意）。
- 保存した身元は取り出せない AES-GCM 鍵で暗号化し、現在オリジンの IndexedDB に `serverURL + siteId` 単位で 7 日。localStorage、cookie、URL には書きません。専用の消去ボタンもありません。
- ブロガー：管理画面でニックネーム、メール、パスフレーズ。公開欄のニックネームにパスフレーズを入れると、サーバが設定済みニックネーム・非公開メール・サイト URL に書き換えます。バッジ既定は `[博主]`。アバターなし。

## 管理

- インスタンス管理者は 1 人。入口 `/admin/`。トークンはページメモリのみ。再読み込みで再ログイン。
- サイト ID は作成後に変更不可。許可オリジン、並び、項目必須、プレースホルダ、Unicode 上限（1–10000、既定 1000）、空状態文を設定。
- コメント：公開 / 墓碑の絞り込み、詳細、墓碑削除。子孫の無い墓碑は完全削除可。
- ボット対策はインスタンス単位の 3 態：オフ、Turnstile、Cap。有効時はコメント送信と管理者ログインの両方。失敗は拒否。自動フォールバックなし。

## 通知

| 投稿者 | 対象 | 配送 |
| --- | --- | --- |
| 訪問者 | ルート | ブロガー SMTP / Telegram |
| 訪問者 | 訪問者 | ブロガー経路 + 親へのメール |
| 訪問者 | ブロガー | ブロガー経路を 1 回 |
| ブロガー | ルート / ブロガー | なし |
| ブロガー | 訪問者 | 親へのメールのみ |

同一メールで自分に返信した場合、訪問者返信メールは送りません。SMTP は `tls` または `starttls` のみ。パスワードと Bot Token は保存時に暗号化。UI は「已设置」のみ表示。

## データとプライバシー

- SQLite3 のみ。マイグレーションはバージョン順・同一ファイル内トランザクション。成功時は版行を追加するだけ。
- 公開 DTO にメール、IP、UA、地域、秘密は含めません。IP はプロセス内のレート制限にだけ短時間使います。
- 既定では `X-Forwarded-For` を信頼しません。訪問者単位の制限は Docker ゲートウェイだけを信頼し、プロキシ側でヘッダを上書きします。

## 組み込み

イメージは `/client/ecoku-loader.js`、`/client/ecoku.umd.js`、`/client/ecoku.css`、構造のみの `/client/ecoku.unstyled.css` を提供します。各ページはコンテナ、`serverURL`、`siteId`、サイト内相対パスの `pageKey` を明示してください。
