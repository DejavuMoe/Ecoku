# v0.1.5

2026-08-17。Schema **v5 → v6**。

## 変更

- インスタンス単位の検証がオフ / Turnstile / セルフホスト Cap の三態になり、コメントと管理者ログインの両方を保護。
- ブラウザは単一の `captchaToken` を送る。
- 停止時コマンド `captcha status` / `captcha disable` を追加。
- 管理 CSP は現在のプロバイダに合わせて絞る。Cap にはインスタンス Origin、WASM、Blob Worker が必要。

移行は `turnstile_settings` を `captcha_settings` に改名し、スイッチと秘密を保持、既定プロバイダを Turnstile にし、Cap フィールドを追加します。

アップグレード手順は [アップグレード](../upgrade)。`v0.1.4` から：tag を `v0.1.5` に変更。Cap を使う場合は Cap Key に管理 Origin と全コメントサイト Origin を許可。ロールバックは停止前の全庫バックアップ復元が必須。すでに v6 に書き込まれた DB は古いイメージへタグだけ戻しても動きません。
