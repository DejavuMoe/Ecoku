## 変更点

- CAPTCHA をインスタンス単位の 3 択（無効、Cloudflare Turnstile、セルフホストの Cap）に変更し、コメント投稿と管理者ログインの両方を保護するようにしました。
- ブラウザは使い捨ての `captchaToken` を送信します。
- 検証の設定ミスでログインできなくなったときに復旧するためのコマンド `captcha status` と `captcha disable` を追加しました。[コマンドライン](../../reference/cli#captcha-disable)を参照してください。
- 管理画面の CSP を現在の検証方式に合わせて調整します。Cap では、インスタンスのオリジン、WebAssembly、Blob Worker の許可が必要です。

## 互換性

schema v6 では、元の `turnstile_settings` テーブルを `captcha_settings` に名前変更し、有効・無効の設定とキーを保持したまま、デフォルトの検証方式を Turnstile とし、Cap 関連のフィールドを追加しました。

Cap に切り替える場合は、Cap の key で管理画面とすべてのコメントサイトのオリジンを許可する必要があります。
