# v0.2.5

- リリース日：2026-09-26
- schema：v8、マイグレーションなし
- イメージ：`git.via.moe/dejavu/ecoku:v0.2.5`

## 変更点

- コメント欄のデフォルトスタイルを「紙と墨」に変更しました。訪問者情報の項目は下線だけの入力欄になり、本文は投稿カードに直接書き込みます。塗りつぶしのメインボタンは 1 つだけで、スタンプ、プレビュー、キャンセル、並び替えは文字だけのボタンになりました。角丸は 6px / 3px です。日時、折りたたみボタン、文字数、ページ番号には等幅フォントを使います。ブロガーバッジ、リンクのホバー、フォームのエラーには朱色を使います。Cap ウィジェットは公式の 260×58px のサイズを保ち、外枠の角丸は Ecoku の変数に従います。
- デフォルトの `--ecoku-*` 変数を詳細度 0 の宣言に変更しました。`.ecoku-comments` に同じ名前の変数を書くだけで上書きでき、セレクターの詳細度を上げる必要はなくなりました。アクセントカラー、エラーカラー、角丸、影、等幅フォント、文字サイズの変数を追加しました。[カスタムスタイル](../../integration/custom-css)を参照してください。
- `data-theme="auto"` で `color-scheme` を固定せず、ページから継承するようにしました。ブログで手動でライト / ダークを切り替えていてシステム設定と一致しない場合でも、コメント欄の配色が反転しなくなりました。
- タッチデバイスでは入力欄の文字サイズを 16px 以上にし、iOS でフォーカス時にページが拡大されないようにしました。
- Turnstile のサーバー側の確認で HTTP リダイレクトを受け取った場合は、検証サービスが利用できないものとして扱い、リクエストを拒否します。

## 互換性

設定項目、環境変数、Compose のマウント、パスワードハッシュに変更はなく、v0.2.4 からその場でアップグレードできます。コメント欄の DOM クラス名と文言、SDK とローダーのインターフェースも変わりません。

見た目の変化に注意してください。

- デフォルトで注入されるスタイルまたは `/client/ecoku.css` を使っているサイトでは、イメージの更新に合わせてコメント欄の見た目が変わります。既存の上書き用 CSS が新しいデフォルト値と重なる可能性があるので、アップグレード後はライトモードとダークモードの両方で確認してください。以前デフォルトのスタイルに勝つために書いた詳細度の高いルールは、`.ecoku-comments` に変数を宣言する形に書き換えられます。
- `data-css-url` で独自のスタイルシートを指定しているサイトや、`none` にしているサイトでは、見た目は変わりません。
- `/client/` 配下のファイルは 1 時間キャッシュされるため、アップグレード後しばらくは古いスタイルが表示される訪問者もいます。

## アップグレード

[アップグレード手順](../upgrade#steps)に従い、イメージを `git.via.moe/dejavu/ecoku:v0.2.5` に変更します。起動後にいくつかの記事を開き、ライトモードとダークモードでコメント欄、返信欄、検証ウィジェットを確認してください。

## v0.2.4 へのロールバック

どちらのバージョンも schema v8 です。サービスを停止し、イメージを `git.via.moe/dejavu/ecoku:v0.2.4` に戻して取得・起動するだけで、既存のデータベースもアップグレード後の新しいコメントも残ります。スタイルと Turnstile のリダイレクトの修正は元に戻ります。
