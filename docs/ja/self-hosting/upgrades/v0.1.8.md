# v0.1.8

2026-08-27。サイトごとに Smoji ステッカーを有効化し、リモートの v1 マニフェスト URL を 1 つ設定できます。選択画面は必要時だけマニフェストを読み込み、ステッカー画像は Ecoku イメージに含めません。本番のマニフェスト URL は HTTPS、画像はマニフェストと同一オリジンである必要があります。

スキーマは v6 から v7 へ、その場でトランザクション移行します。`sites` に `smoji_enabled` と `smoji_manifest_url` を追加します。既存サイトは無効・空 URL のままです。環境変数、設定キー、Compose マウント、コンテナ権限の追加はありません。

[アップグレード](../upgrade) に従ってください。`v0.1.7` からは、停止してコールドバックアップを取り、Compose の tag を正確な `v0.1.8` に変更し、`sudo docker compose config --quiet`、`sudo docker compose pull`、`sudo docker compose up -d` を実行します。その後、ログ、`docker compose ps`、`/api/health`、コメント、管理画面を確認してください。起動時に v6 → v7 移行が自動実行されます。

tag を `v0.1.7` に戻すだけではロールバックできません。新バージョンが v7 を書き込んだ場合は、停止してアップグレード前のデータベース全体のバックアップを復元してから `v0.1.7` を起動してください。
