## 変更点

- サイトで Smoji スタンプパックを有効にし、リモートの v1 一覧 URL を 1 つ指定できるようになりました。一覧は、訪問者が初めてスタンプピッカーを開いたときに読み込まれます。スタンプ画像は Ecoku のイメージには同梱されません。
- 本番環境では、一覧の URL は HTTPS でなければならず、スタンプ画像は一覧と同じオリジンでなければなりません。
- 選んだスタンプは `![smoji:名前](完全な画像URL)` という純テキストの形式で保存されます。機能を無効にすると、過去の記法は原文のまま表示されます。

## 互換性

schema v7 では、サイトのテーブルに Smoji の有効・無効と一覧アドレスの 2 つのフィールドを追加しました。既存のサイトはデフォルトで無効です。新しい環境変数、設定項目、マウント、権限の要件はありません。
