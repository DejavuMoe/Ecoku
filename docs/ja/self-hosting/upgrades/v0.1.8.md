# v0.1.8

- リリース日：2026-08-27
- schema：v6 → v7
- イメージ：`git.via.moe/dejavu/ecoku:v0.1.8`

## 変更点

- サイトで Smoji スタンプパックを有効にし、リモートの v1 一覧 URL を 1 つ指定できるようになりました。一覧は、訪問者が初めてスタンプピッカーを開いたときに読み込まれます。スタンプ画像は Ecoku のイメージには同梱されません。
- 本番環境では、一覧の URL は HTTPS でなければならず、スタンプ画像は一覧と同じオリジンでなければなりません。
- 選んだスタンプは `![smoji:名前](完全な画像URL)` という純テキストの形式で保存されます。機能を無効にすると、過去の記法は原文のまま表示されます。

## 互換性

schema v7 では、サイトのテーブルに Smoji の有効・無効と一覧アドレスの 2 つのフィールドを追加しました。既存のサイトはデフォルトで無効です。新しい環境変数、設定項目、マウント、権限の要件はありません。

## アップグレード

1. [バックアップと復元](../backup#cold-backup)の手順で、サービスを停止してコールドバックアップを取ります。
2. [アップグレード手順](../upgrade#steps)に従い、イメージを `git.via.moe/dejavu/ecoku:v0.1.8` に変更します。起動時に自動で v7 にマイグレーションされます。
3. コメント欄と管理画面を確認します。

## ロールバック

データベースが v7 にマイグレーションされると、v0.1.7 では開けません。ロールバックするには、サービスを停止し、アップグレード前のコールドバックアップから[復元](../backup#restore)してから、v0.1.7 で起動する必要があります。バックアップ後の新しいデータは失われます。
