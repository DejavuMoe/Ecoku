# v0.1.3

- リリース日：2026-08-15
- schema：v4 → v5
- イメージ：`git.via.moe/dejavu/ecoku:v0.1.3`

## 変更点

- ブロガーを合言葉による認証に変更しました。コメント欄のニックネーム欄に合言葉を入力すると、ブロガーとして投稿されます。
- 通知はキューに入る時点で宛先ごとに複数のレコードに分割され、1 件ずつ再試行されます。通知プロセスの起動時に、「処理中」のレコードをすべて回収します。
- SMTP は TLS または STARTTLS だけを許可します。
- サイト管理キーでコメントの一覧と詳細を読み取れなくなりました（`403` を返します）。残るのは、そのサイトのコメントの墓標削除だけです。
- `trusted_proxies` に `0.0.0.0/0` や `::/0` を指定することを禁止しました。

## 互換性

schema v5 では、ブロガーの合言葉のハッシュ、コメントのブロガーの印、通知キューの宛先フィールドを追加しました。v0.1.3 では、サイトにブロガーの合言葉を設定すると、ブロガーのニックネームとメールアドレスをもとに過去のコメントにブロガーの印を補完します。

アップグレード後、ブロガーとして発言を続けるには、管理画面でサイトにブロガーの合言葉を設定する必要があります。

## アップグレード

1. [バックアップと復元](../backup#cold-backup)の手順で、サービスを停止してコールドバックアップを取ります。
2. [アップグレード手順](../upgrade#steps)に従い、イメージを `git.via.moe/dejavu/ecoku:v0.1.3` に変更します。
3. 管理画面にログインし、必要なサイトにブロガーの合言葉を設定します。

## ロールバック

データベースが v5 にマイグレーションされると、v0.1.2 では開けません。ロールバックするには、イメージを `v0.1.2` に戻し、アップグレード前のコールドバックアップから[復元](../backup#restore)する必要があります。
