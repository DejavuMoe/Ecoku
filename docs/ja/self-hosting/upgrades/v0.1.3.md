# v0.1.3

2026-08-15。Schema **v4 → v5**。

## 変更

- ブロガーはパスフレーズ証明：公開側はニックネーム欄にパスフレーズだけ入力。
- 通知はエンキュー時に宛先ごとに outbox 行を分割。ワーカー起動時にすべての `processing` 行を回収。
- SMTP は TLS / STARTTLS のみ。
- management key はコメント GET 一覧/詳細で 403。所属サイトの墓碑削除のみ残す。
- `trusted_proxies` に `0.0.0.0/0` や `::/0` を禁止。

移行はブロガーパスフレーズハッシュ、`comments.is_blogger`、outbox `target` を追加。起動後に管理画面でパスフレーズを設定すると過去のブロガーコメントが埋め戻されます。

アップグレード手順は [アップグレード](../upgrade)。`v0.1.2` から：tag を `v0.1.3` に変更。ロールバックは `v0.1.2` に戻し、**かつ** 停止前の全庫バックアップで復元。すでに v5 の DB は `v0.1.2` では動きません。
