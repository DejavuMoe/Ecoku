# v0.2.0

- リリース日：2026-09-12
- schema：v7、マイグレーションなし
- イメージ：`git.via.moe/dejavu/ecoku:v0.2.0`

## 変更点

このバージョンは主にドキュメントの改訂です。API、設定、デプロイ、バックアップと復元、リバースプロキシ、Twikoo のインポートの説明を修正し、コメント一覧の読み込み予算、階層ごとの読み込み、レート制限、ステータスコードの説明を補って、v0.1.9 の実装と一致させました。ランタイムの動作に変更はありません。

## 互換性

環境変数、Compose のマウント、ポート、コンテナの権限、データ形式はいずれも変わらず、v0.1.9 からその場でアップグレードできます。

## アップグレードとロールバック

[アップグレード手順](../upgrade#steps)に従い、イメージを `git.via.moe/dejavu/ecoku:v0.2.0` に変更します。

v0.1.9 にロールバックするときは、サービスを停止してからイメージを `git.via.moe/dejavu/ecoku:v0.1.9` に戻して起動します。両バージョンのスキーマは同じです。
