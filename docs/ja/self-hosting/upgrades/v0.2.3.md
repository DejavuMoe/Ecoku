# v0.2.3

- リリース日：2026-09-16（Git tag）
- schema：v7、マイグレーションなし
- イメージ：`git.via.moe/dejavu/ecoku:v0.2.3`

## 変更点

- サイト設定を保存するときに、過去のコメントにブロガーの印を付け直さないようにしました。ブロガーの合言葉に「UTF-8 で 72 バイト以内」の検証を追加しました。設定済みの合言葉は引き続き有効です。
- SMTP の送信処理全体をキャンセルできるようになり、20 秒のタイムアウトがかかります。通知を送った後に状態の書き戻しに失敗した場合は、書き戻しだけを再試行し、重複して送信しません。Telegram のメッセージは完全なリンクと HTML の構造を保持します。
- Twikoo のインポートで、レコードの順序がばらばらでも親子関係を正しく復元できるようになりました。
- コメントと管理画面の入力が Unicode 文字全体に対応しました。管理画面のリクエストのキャンセルとタイムアウト処理、ローダーの再試行、Smoji のアドレスとキーボード操作など、多数の修正を行いました。
- SDK の `setPageKey(pageKey, pageTitle)` で記事タイトルも同時に更新できるようになりました。2 つ目の引数を省略すると古いタイトルは消去されます。

## 互換性

マウント、環境変数、パスワードハッシュの形式は変わらず、v0.2.2 からその場でアップグレードできます。コメント、設定、WAL ファイル、バックアップは削除されません。

- 既存のブロガーの印はそのまま残ります。旧バージョンではサイトの保存時に一部のコメントに誤って印を付けた可能性がありますが、それらのレコードは実際に合言葉で投稿されたコメントと自動では区別できないため、このバージョンでは一括で変更しません。誤った印を見つけた場合は、個別に確認してから対処してください。
- 通知は「少なくとも 1 回」配信されます。通知を送った後、結果を記録する前にプロセスがクラッシュすると、再起動後にもう一度送られることがあります。

## アップグレード

[アップグレード手順](../upgrade#steps)に従い、イメージを `git.via.moe/dejavu/ecoku:v0.2.3` に変更します。起動後、管理画面にログインできること、過去のコメントとブロガーバッジが正しく表示されることを確認してください。通知を確認したい場合は、テストメールまたはテストメッセージを手動で送ってください。

## v0.2.2 へのロールバック

どちらのバージョンも schema v7 です。サービスを停止し、イメージを `git.via.moe/dejavu/ecoku:v0.2.2` に戻して取得・起動すれば、既存のデータベースも新しいコメントも残ります。このバージョンで修正した問題も元に戻ります。
