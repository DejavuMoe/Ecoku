# v0.1.7

2026-08-26。Schema は v6 のままです。

## 変更

本リリースでは、ローカル開発、CI、コンテナビルド、文書サイトのビルド/公開フローを更新しました。ツールチェーンは Node.js 24.19.0、Go 1.27.0、pnpm 11.24.0 に固定し、実行時イメージは Alpine 3.24.1 のままです。アプリケーションの実行時契約は変わりません。

## アップグレード

新しい環境変数、設定キー、Compose マウントはありません。コンテナは引き続き UID/GID `10001:10001` で実行し、`/data`、設定、ログのマウント先も変わらないため、既存の `v0.1.6` インスタンスで権限を変更する必要はありません。

Compose ファイル全体を置き換えないでください。既存のリソース制限とマウントを残し、正確なイメージタグだけを `git.via.moe/dejavu/ecoku:v0.1.7` に変更します。古いファイルに `logging` セクションがなければ、現行リポジトリのものを追加します。

`v0.1.6` からの更新：

1. サービスを停止し、`data/`、`app/config.yaml`、`app/logs/`、`ecoku.env`、現在の Compose ファイルをコールドバックアップします。
2. 正確なイメージタグを `v0.1.7` に変更します。
3. 実行します。

```bash
sudo docker compose config --quiet
sudo docker compose pull
sudo docker compose up -d
sudo docker compose ps
sudo docker compose logs --tail=200 ecoku
curl --fail http://127.0.0.1:12123/api/health
```

ロールバック時は再び `v0.1.6` を固定します。両版とも schema v6 のため通常はデータベースを置き換える必要はありませんが、起動または検証に失敗した場合は更新前のバックアップを復元してください。
