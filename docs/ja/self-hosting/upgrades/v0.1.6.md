# v0.1.6

2026-08-18。Schema は引き続き v6。

## 変更

Cap instrumentation 有効時、管理画面は Cap が現在の方式のときだけ `script-src 'unsafe-eval'` を追加で許可します。オフに戻すか Turnstile に切り替えるとその緩和は撤回されます。`'wasm-unsafe-eval'` は JavaScript の `'unsafe-eval'` の代わりになりません。受け入れられない場合は instrumentation をオフにするか Turnstile に切り替えてください。

アップグレード手順は [アップグレード](../upgrade)。`v0.1.5` から：tag を `v0.1.6` に変更。新しい環境変数やマウントはありません。ロールバックは `v0.1.5`（同一 schema。通常は DB の差し替え不要）。
