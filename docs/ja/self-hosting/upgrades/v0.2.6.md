## 変更

- 管理画面をコメント欄のデフォルトスタイルと同じ紙と墨の配色（ライトとダーク）に変更し、角丸を 6px / 3px にしました。UI フォントは OS に搭載された中国語・欧文フォントを使い、Web フォントは読み込みません。
- サイトの切り替えを上部バーから「コメント管理」（评论管理）の一覧の左上に移しました。サイトが 1 つだけのときはサイト名をそのまま表示します。「通知設定」（通知设置）と「セキュリティ」（安全）にはサイト選択を表示しなくなりました。
- 「コメント管理」：「元のコメントを表示」（查看原评论）、「墓標削除」（墓碑删除）、「完全削除」（彻底删除）を詳細の上部に移しました。返信が残っている墓標には「仍有回复，不能彻底删除」（返信が残っているため完全削除できません）と表示されます。削除の確認ダイアログに対象のコメントを表示します。一覧に読み込み中と読み込み失敗の状態を追加し、失敗時は再試行できます。上下の矢印キーで一覧のコメントを切り替えられます。
- 「サイト管理」（站点管理）：フォームを基本情報、コメント欄、スタンプパック、ブロガー身元に分けました。保存ボタンは下部に固定され、入力チェックに失敗すると修正が必要な件数を表示し、最初のエラーにフォーカスを移します。
- 「通知設定」：暗号化方式を SSL/TLS と STARTTLS の 2 択にしました。チャネルを無効にすると項目を折りたたみます。常にチェックされていた「訪問者に返信が付いたとき」（访客收到回复时）の項目を削除しました。訪問者への返信通知は引き続きメールチャネルと一緒に有効・無効になります。
- ドキュメントサイトをソースコードに基づいて書き直しました。[アップグレード](../upgrade)と各ページを参照してください。

## 互換性

設定項目、環境変数、Compose のマウント、管理 API、データベースはいずれも変わりません。v0.2.5 からその場でアップグレードできます。コメント欄と SDK には影響しません。

管理画面のページ自体はキャッシュされないため、アップグレード後に再読み込みすると新しい画面になります。すでに開いている管理画面のタブは一度再読み込みしてください。

## 過去の移行上の注意 {#upgrade}

このバージョンは記録用です。インストールやダウングレードの手順は提供しません。異なる schema に戻すには、対象バージョンに対応した完全なコールドバックアップが必要です。
