# 博主身份

博主不需要单独的账号。给站点设置一个口令后，你在自己博客的评论区里把口令填进昵称栏，就能以博主身份发言，评论带上博主标志。

<div class="steps">

### 在站点里填写博主信息

在后台「站点」里编辑站点，找到博主相关字段：

| 字段 | 说明 |
| --- | --- |
| 博主昵称 | 公开显示的名字，最多 80 个字符 |
| 博主邮箱 | 不公开，保存为博主评论的邮箱。博主通知发到「通知」页的收件人，不是这里。 |
| 博主口令 | 12～80 个字符，不超过 72 个 UTF-8 字节，不能换行。保存后不再显示，留空表示不修改。 |
| 评论区标志 | 显示在昵称后的文字，默认 `[博主]`，最多 16 个字符，留空则不显示 |

昵称和邮箱要么都填，要么都留空；都填时必须设置口令。

### 在评论区发言

在博客的评论框里：

- **昵称**：填博主口令
- **邮箱**、**网址**：留空

直接发布。服务端认出口令后，会把这条评论的昵称、网址、邮箱换成博主昵称、站点 URL 和博主邮箱，并加上博主标志。浏览器不会把口令记成你的昵称。

</div>

::: warning 口令输错时
输错的口令会被当成普通昵称。如果站点的邮箱是选填，这条评论会以口令文字为昵称公开发布。发现后到「评论」里删掉它，并更换口令。
:::

## 关闭博主身份

把博主昵称和邮箱都清空并保存，口令也会一起清除。

## 已有评论的标记

博主标记在评论保存时写入，之后不再重新计算。改昵称、换口令，都不会影响已有评论的标记。

只有两种情况会按昵称和邮箱回填历史评论：

- 从旧版本升级到 schema v5 时的一次性迁移；
- [从 Twikoo 导入](../self-hosting/twikoo) 时，昵称完全一致且邮箱一致（不区分大小写）的评论会标为博主评论。

博主的评论不会触发给你自己的通知，规则见 [通知 · 什么时候发](./notifications#when)。
