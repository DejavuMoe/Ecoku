# 处理评论

Ecoku 没有审核队列，评论提交后立即公开。你在后台「评论」页查看所有评论，删掉不该留下的。

## 查看评论

「评论」页分「已发布」和「已删除」两栏，每页 20 条，按日期分组，可以切换最新或最早在前。每条评论显示：

- 正文、时间、文章标题和页面 key
- 访客填写的邮箱和网站（这些不会公开）
- 如果是回复，引用它回复的那条评论

点「查看原评论」会在新标签页打开文章，并跳到这条评论。

## 删除评论 {#delete}

删除有两种，都**不能撤销**。

| | 墓碑删除 | 彻底删除 |
| --- | --- | --- |
| 在哪里 | 「已发布」里的任意评论 | 「已删除」里没有回复的评论 |
| 结果 | 清空昵称、邮箱、网址和正文，保留它在讨论中的位置 | 从数据库中移除 |
| 访客看到 | 「已删除」和「[该评论已删除]」，下面的回复照常显示 | 评论消失 |

先墓碑删除，是为了不让下面的回复失去上下文。墓碑下面还有回复时不能彻底删除，后台会显示「仍有回复，不能彻底删除」。

被墓碑删除的评论不能再被回复。

## 删除对通知的影响

删除一条评论后，与它有关、还没发出的通知不再发送；已经发出的 Telegram 消息会被改写为删除提示。已经发出的邮件无法撤回。详见 [通知 · 删除评论之后](./notifications#after-deletion)。

## 用脚本删除评论

需要用自动化脚本删评论时，可以给站点配置一个站点管理凭据，它只能对这个站点的评论做墓碑删除。见 [配置文件](../reference/configuration) 中 `sites[].management_key_env` 的注释，以及 [HTTP API · 认证方式](../reference/api#auth)。
