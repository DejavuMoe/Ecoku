# 特性全览

Ecoku 在保持极简架构的同时，提供了完善的评论交互、现代安全机制、优雅排版与灵活定制能力。

---

## 评论交互体验

- **提交即时公开**：无任何前置人工审核阻塞，发表成功后即刻呈现在评论列表中。
- **无限语义与 3 级视觉缩进**：底层数据支持无限层级嵌套回复；前端视觉采用智能阶梯缩进，最多缩进 3 级，深层回复自动呈现 `@被回复者` 可点击锚点，窄屏无压力。
- **根线程分页模型**：预算内按根评论批次返回完整讨论树；超预算明确报错，不静默截断。大线程可通过[单层游标 API](../reference/api.md)按需读取。
- **等宽折叠控件**：折叠控件 `[+]` 与 `[-]` 固定为 `3ch` 等宽，配合等宽字体与 `tabular-nums`，折叠切换时元信息行零抖动。
- **墓碑式软删除**：删除评论时保留结构墓碑，正文显示为 `[该评论已删除]`，保障下游讨论上下文不被腰斩。
- **Smoji 纯文本贴图**：支持站点级自定义表情包，采用 `![smoji:标签](url)` 纯文本标记存储，客户端同源按需加载，安全无痕。

## 身份认证与隐私保护

- **灵活字段控制**：昵称始终必填；私有邮箱与个人网站由站点配置决定是否必填（默认邮箱必填、网站可选）。
- **客户端 AES-GCM 加密存储**：访客填写的身份信息通过 WebCrypto API 生成 256 位密钥加密存于 IndexedDB，7 天后自动静默失效，绝不落盘于 `localStorage` 或 Cookie。
- **博主免密口令（Passphrase）**：博主只需在昵称框输入口令即可自动点亮博主徽章并完成身份认证，无需在公共设备暴露私有邮箱。
- **严格零隐私泄漏**：公开 API DTO 严格剔除邮箱、IP、User-Agent、地理位置等敏感数据；日志系统同样绝不记录隐私字段。

## 现代化安全与人机防护

- **三态人机验证切换**：实例级自由切换 **关闭 (`off`)**、**Cloudflare Turnstile** 或 **自托管 Cap**。
- **端到端凭据加密**：数据库内存储的 Turnstile Secret、Cap Secret、SMTP 密码及 Telegram Token 均由主密钥采用 AES-256-GCM 强加密保存，管理端仅显示“已设置”，永不回显明文。
- **动态 CSP 安全收敛**：管理端 Content-Security-Policy 随当前验证提供方动态收敛，仅在启用 Cap 时精准放行其 HTTPS 实例域名与必要求值权限，其余模式全面收紧。
- **多维度单进程限流**：内置基于 Socket 对端 IP 与可信反代网关的内存限流器，对评论提交、删除、管理登录与通知测试施加精准频控。

## 运维与基础设施

- **单容器极简交付**：Go 单二进制一体化托管 API、管理后台与前端 SDK，依赖零膨胀。
- **SQLite3 WAL 模式**：高并发读写性能，原位顺序版本化迁移（v1～v7），安全可靠。
- **Outbox 事务一致性通知**：评论写入与通知入队原子提交，支持 SMTP（TLS/STARTTLS）与 Telegram 机器人双渠道，按目标拆行独立重试。
- **Twikoo 零损迁移工具**：内置 CLI 工具，支持从 Twikoo 导出数据平滑导入，自动清洗转换层级与 Markdown 标记，静默无通知导入。
- **双主题与完整 Design Tokens**：评论区与管理端均原生支持深浅色自适应，提供全套 CSS 变量方便快速融入各类博客设计。
