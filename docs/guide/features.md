# 特性

## 评论

- 纯文本，提交即公开。
- 多层线程；视觉缩进最多三级。公开列表按根线程分页，当前页包含这批根评论的全部公开后代。
- 回复在被回复评论下方完成。缺少身份时就在该回复框采集，不会误发成根评论。
- 排序：站点默认「最新」或「最早」，访客可临时切换。
- 删除后保留墓碑：固定昵称「已删除」、正文「[该评论已删除]」，不可再回复。

## 身份

- 昵称始终必填。邮箱、网站是否必填按站点配置，默认邮箱必填、网站可选。
- 已填写的身份用非导出 AES-GCM 密钥加密，存入当前 Origin 的 IndexedDB，按 `serverURL + siteId` 隔离，7 天后失效。不写 localStorage、cookie 或 URL，也没有单独的清除按钮。
- 博主：管理端配置昵称、邮箱和口令。公开区只在昵称栏填口令，服务端改写为配置昵称、私有邮箱和站点 URL。徽章默认 `[博主]`，无头像。

## 管理

- 单一实例管理员，入口 `/admin/`。Token 只在当前页内存，刷新需重新登录。
- 站点 ID 创建后不可改。可配置允许来源、排序、字段要求、占位文案、Unicode 上限（1–10000，默认 1000）和空状态文案。
- 评论管理：按已发布 / 墓碑筛选、详情、墓碑删除；无后代墓碑可彻底删除。
- 机器人验证为实例级三态：关闭、Cloudflare Turnstile、自托管 Cap。启用时同时保护评论提交和管理员登录；失败则拒绝，不会自动降级。

## 通知

| 提交者 | 对象 | 结果 |
| --- | --- | --- |
| 访客 | 根评论 | 博主 SMTP / Telegram |
| 访客 | 访客 | 博主渠道 + 被回复者邮件 |
| 访客 | 博主 | 博主渠道一次 |
| 博主 | 根评论 / 博主 | 不发送 |
| 博主 | 访客 | 仅被回复者邮件 |

同一邮箱回复自己不发访客回复邮件。SMTP 只允许 `tls` 或 `starttls`。密码与 Bot Token 加密入库，界面只显示「已设置」。

## 数据与隐私

- 只使用 SQLite3。迁移按版本顺序、在原文件内事务执行；成功只追加版本记录。
- 公共 DTO 不含邮箱、IP、UA、地区或密钥。IP 只在进程内短暂用于限流。
- 默认不信任 `X-Forwarded-For`。按人限流时只信任 Docker 网关，由反代覆盖转发头。

## 接入

镜像提供 `/client/ecoku-loader.js`、`/client/ecoku.umd.js`，以及 `/client/ecoku.css` 与结构用 `/client/ecoku.unstyled.css`。页面必须显式给出容器、`serverURL`、`siteId` 和站内相对路径 `pageKey`。
