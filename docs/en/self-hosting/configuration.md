# Configuration Reference

Complete reference for `app/config.yaml` and `ecoku.env`.

`rate_limit.comment_list` allows 60 public list reads per IP per `window_seconds` window by default (60 seconds). Both list modes share the bucket; other actions use separate buckets. Exceeding the limit returns 429 with `Retry-After`. Each limiter retains at most 10,000 active address buckets, rejecting new addresses when full until entries expire. Existing `trusted_proxies` rules apply; visitors behind an untrusted proxy share its IP quota.

List admission runs before CORS queries, including preflights and rejected origins. Early rejections do not add unverified cross-origin permissions, so a cross-origin browser may only show a load failure. If cancellation replaces a SQLite connection, foreign-key, synchronous and busy-timeout settings are reapplied automatically.

## `app/config.yaml` Reference

```yaml
site:
  port: 12123
  log_path: "/var/log/ecoku/ecoku.log"
  trusted_proxies:
    - "172.18.0.1/32"

client:
  static_dir: "/app/client"

rate_limit:
  window_seconds: 60
  comment_submit: 5
  comment_list: 60
  comment_delete: 30
  admin_login: 5
  notification_test: 5

notifications:
  encryption_key_env: "ECOKU_NOTIFICATION_ENCRYPTION_KEY"
  instance_public_url: "https://comments.example.com"

database:
  sqlite:
    path: "/data/ecoku.sqlite3"

admin:
  enabled: true
  static_dir: "/app/admin"
  username_env: "ECOKU_ADMIN_USERNAME"
  password_hash_env: "ECOKU_ADMIN_PASSWORD_HASH"
  token_key_env: "ECOKU_ADMIN_TOKEN_KEY"
  token_ttl_minutes: 480
  allowed_origins:
    - "https://comments.example.com"
```

## Environment Variables `ecoku.env`

| Variable | Required | Description | Example / Tool |
| :--- | :---: | :--- | :--- |
| `GIN_MODE` | No | Gin engine mode | `release` |
| `TZ` | No | IANA Timezone | `Asia/Shanghai` |
| `ECOKU_ADMIN_USERNAME` | Yes | Admin username | `admin` |
| `ECOKU_ADMIN_PASSWORD_HASH` | Yes | Admin bcrypt password hash | Generated by `ecoku-server hash-password` |
| `ECOKU_ADMIN_TOKEN_KEY` | Yes | HMAC signing key (>= 32 chars) | `openssl rand -hex 32` |
| `ECOKU_NOTIFICATION_ENCRYPTION_KEY` | Yes | AES-256-GCM master key (Base64 32 bytes) | `openssl rand -base64 32` |
