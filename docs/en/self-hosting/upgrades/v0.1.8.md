# v0.1.8

2026-08-27. Sites may enable Smoji stickers and configure one remote v1 manifest URL. The picker loads the manifest on demand; sticker assets are not bundled into the Ecoku image. Production manifest URLs must use HTTPS, and images must be same-origin with the manifest.

The schema migrates in place, transactionally, from v6 to v7. It adds `smoji_enabled` and `smoji_manifest_url` to `sites`. Existing sites remain disabled with an empty URL. No new environment variables, configuration keys, Compose mounts, or container permission requirements are introduced.

Follow [Upgrade](../upgrade). From `v0.1.7`: stop and take a cold backup, change Compose to the exact tag `v0.1.8`, run `sudo docker compose config --quiet`, `sudo docker compose pull`, and `sudo docker compose up -d`, then check logs, `docker compose ps`, `/api/health`, comments, and the admin UI. Startup runs the v6 → v7 migration automatically.

Rollback cannot be done by changing the tag back to `v0.1.7` alone. If the new version has written v7, stop the service and restore the full pre-upgrade database backup before starting `v0.1.7`.
