# v0.1.6

- Release date: 2026-08-18
- Schema: v6, no migration
- Image: `git.via.moe/dejavu/ecoku:v0.1.6`

## Changes

When Cap has instrumentation (runtime detection) enabled, it needs to run dynamic scripts. In this release, when Cap is the current verification mode, the admin console's CSP additionally allows `script-src 'unsafe-eval'`. The allowance is withdrawn when you turn verification off or switch back to Turnstile. `'wasm-unsafe-eval'` cannot replace `'unsafe-eval'`. If you do not accept this allowance, turn off instrumentation in Cap, or use Turnstile instead.

## Compatibility

There are no new environment variables or mounts. You can upgrade in place from v0.1.5.

## Upgrade and rollback

Follow the [upgrade steps](../upgrade#steps) and change the image to `git.via.moe/dejavu/ecoku:v0.1.6`.

To roll back to v0.1.5, stop the service, change the image back to `git.via.moe/dejavu/ecoku:v0.1.5`, and start it. Both releases have the same schema.
