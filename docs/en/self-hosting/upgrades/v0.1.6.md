# v0.1.6

2026-08-18. Schema stays v6.

Cap 3.x instrumentation calls `eval` / `new Function`. Admin CSP adds `script-src 'unsafe-eval'` only while Cap is the active provider, for that exact origin, WASM, Blob Worker, and nonce. Turning Cap off or switching to Turnstile tightens CSP again.

`'wasm-unsafe-eval'` is not a substitute. If you reject that trade-off, disable instrumentation on the Cap Key or use Turnstile.

From `v0.1.5`: cold backup → pin `v0.1.6` → `pull && up -d`. No new env or mounts. Rollback to `v0.1.5` usually keeps the same database.
