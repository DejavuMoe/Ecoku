# v0.1.6

2026-08-18. Schema remains v6.

## Changes

When Cap instrumentation is enabled, the admin UI additionally allows `script-src 'unsafe-eval'` only while Cap is the current provider. That relaxation is revoked when Cap is turned off or switched back to Turnstile. `'wasm-unsafe-eval'` cannot replace JavaScript `'unsafe-eval'`. If that is unacceptable, disable instrumentation or switch to Turnstile.

Upgrade steps: [Upgrade](../upgrade). From `v0.1.5`: change the tag to `v0.1.6`. No new environment variables or mounts. Roll back to `v0.1.5` (same schema; usually no database swap).
