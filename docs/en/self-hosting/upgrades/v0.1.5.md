# v0.1.5

2026-08-17. Schema **v5 → v6**.

## Changes

- Instance verification becomes a tri-state: off / Turnstile / self-hosted Cap, protecting both comments and admin login.
- The browser submits a single `captchaToken`.
- Adds stopped-service commands `captcha status` / `captcha disable`.
- Admin CSP tightens to the current provider; Cap needs the instance Origin, WASM, and Blob Worker.

Migration renames `turnstile_settings` to `captcha_settings`, keeps the switch and secrets, defaults the provider to Turnstile, then adds Cap fields.

Upgrade steps: [Upgrade](../upgrade). From `v0.1.4`: change the tag to `v0.1.5`. If using Cap, allow the admin Origin and every comment-site Origin on the Cap Key. Rollback must restore the full pre-stop database backup; a database already at v6 cannot run on an older image by tag alone.
