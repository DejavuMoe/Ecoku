# v0.1.5

2026-08-17. Schema **v5 → v6**.

Bot protection becomes off / Turnstile / Cap. Adds `captcha status` / `captcha disable`. Cap Siteverify rejects redirects, localhost, private nets, and non-public DNS.

Migration renames `turnstile_settings` to `captcha_settings` and adds Cap fields. Cold backup is mandatory. A v6 database cannot run on an older image without restoring the backup.

From `v0.1.4`: pin `v0.1.5` then `pull && up -d`. If you choose Cap, allow admin and all comment Origins on the Cap Key.
