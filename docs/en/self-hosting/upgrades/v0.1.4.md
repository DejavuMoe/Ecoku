# v0.1.4

- Release date: 2026-08-15
- Schema: v5, no migration
- Image: `git.via.moe/dejavu/ecoku:v0.1.4`

## Changes

Saving the blogger passphrase in the admin console backfills the blogger mark on existing comments by matching the blogger nickname and email.

::: info
This behavior was removed in [v0.2.3](./v0.2.3). The current release does not modify any existing comments when you save site settings.
:::

## Upgrade and rollback

Follow the [upgrade steps](../upgrade#steps) and change the image to `git.via.moe/dejavu/ecoku:v0.1.4`.

To roll back to v0.1.3, stop the service, change the image back to `git.via.moe/dejavu/ecoku:v0.1.3`, and start it. Both releases have the same schema.
