## Changes

Saving the blogger passphrase in the admin console backfills the blogger mark on existing comments by matching the blogger nickname and email.

::: info
This behavior was removed in [v0.2.3](./v0.2.3). The current release does not modify any existing comments when you save site settings.
:::
