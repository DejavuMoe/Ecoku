# v0.2.0

- Release date: 2026-09-12
- Schema: v7, no migration
- Image: `git.via.moe/dejavu/ecoku:v0.2.0`

## Changes

This release is mostly documentation revisions. It corrects the descriptions of the API, configuration, deployment, backup and restore, reverse proxy, and Twikoo import, and adds descriptions of the comment list's read budget, level-by-level reads, rate limits, and status codes, so that they match the v0.1.9 implementation. Runtime behavior is unchanged.

## Compatibility

Environment variables, Compose mounts, ports, container permissions, and data format are unchanged. You can upgrade in place from v0.1.9.

## Upgrade and rollback

Follow the [upgrade steps](../upgrade#steps) and change the image to `git.via.moe/dejavu/ecoku:v0.2.0`.

To roll back to v0.1.9, stop the service, change the image back to `git.via.moe/dejavu/ecoku:v0.1.9`, and start it. Both releases have the same schema.
