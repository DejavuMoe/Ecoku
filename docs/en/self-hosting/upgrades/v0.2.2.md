# v0.2.2

- Release date: 2026-09-13
- Schema: v7, no migration
- Image: `git.via.moe/dejavu/ecoku:v0.2.2`

## Changes

The sticker picker is now aligned to the right side of the comment box's or reply box's bottom bar and is no wider than the bar. This fixes the popup overflowing the left edge of the page on narrow screens. Both the default styles and the structural styles are updated accordingly.

## Compatibility

Config, environment variables, and mounts are unchanged. You can upgrade in place from v0.2.1.

## Upgrade and rollback

Follow the [upgrade steps](../upgrade#steps) and change the image to `git.via.moe/dejavu/ecoku:v0.2.2`.

To roll back to v0.2.1, stop the service, change the image back to `git.via.moe/dejavu/ecoku:v0.2.1`, and start it. Both releases have the same schema.
