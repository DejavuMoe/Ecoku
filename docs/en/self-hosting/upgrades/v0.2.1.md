- Release date: 2026-09-12
- Schema: v7, no migration
- Git tag: [v0.2.1](https://github.com/DejavuMoe/Ecoku/tree/v0.2.1)

## Changes

- Smoji manifest capacity is raised to 64 groups, 600 items per group, 6000 items in total, with a file size limit of 1 MiB (counted in UTF-8 bytes). The 8-second timeout covers the complete download. Validation of the JSON type, control characters in labels, and image URLs is added.
- Manifests gain an optional `base` URL template, so entries can omit repetitive `src` values. The old format is still supported. See [Smoji sticker packs](../../integration/smoji#base).

## Compatibility

Config, environment variables, and mounts are unchanged. You can upgrade in place from v0.2.0. Old manifests do not need changes.

Manifests that use the `base` template cannot be parsed by v0.2.0. If you might need to roll back, keep a copy of the manifest that writes out `src` for every item and stays within v0.2.0's capacity (32 groups, 300 items per group, 2000 items in total, 256 KiB).

## Historical upgrade notes {#upgrade}

This version is archived, with no installation or downgrade instructions. Restoring across schemas requires a complete cold backup matching the target version; changing an image alone is insufficient.
