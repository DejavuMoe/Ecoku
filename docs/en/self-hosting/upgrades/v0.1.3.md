# v0.1.3

2026-08-15. Schema **v4 → v5**.

Blogger identity is passphrase-proved. Outbox rows split per recipient; the worker reclaims `processing` rows on start. SMTP is TLS/STARTTLS only. Management keys get 403 on comment GET list/detail. `trusted_proxies` cannot be `0.0.0.0/0` or `::/0`.

From `v0.1.2`: cold backup (no WAL/SHM) → pin `v0.1.3` → `pull && up -d`. Set the passphrase in admin so history is backfilled.

Rollback requires `v0.1.2` **and** the pre-upgrade database.
