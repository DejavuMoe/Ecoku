# v0.1.3

2026-08-15. Schema **v4 → v5**.

## Changes

- Bloggers prove identity with a passphrase: on the public form, enter only the passphrase in the nickname field.
- Notifications split into one outbox row per recipient at enqueue time; on worker start all `processing` rows are reclaimed.
- SMTP allows only TLS / STARTTLS.
- Management key returns 403 for comment GET list/detail; only tombstone deletion for owned sites remains.
- `trusted_proxies` may not be `0.0.0.0/0` or `::/0`.

Migration adds the blogger passphrase hash, `comments.is_blogger`, and outbox `target`. After start, set the passphrase in the admin UI to backfill historical blogger comments.

Upgrade steps: [Upgrade](../upgrade). From `v0.1.2`: change the tag to `v0.1.3`. Rollback must pin `v0.1.2` **and** restore the full pre-stop database backup; a database already at v5 cannot run on `v0.1.2`.
