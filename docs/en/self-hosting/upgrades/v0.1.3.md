- Release date: 2026-08-15
- Schema: v4 → v5
- Git tag: [v0.1.3](https://github.com/DejavuMoe/Ecoku/tree/v0.1.3)

## Changes

- The blogger switches to passphrase authentication: enter the passphrase in the nickname field of the comment section to post as the blogger.
- Notifications are split into one record per recipient when queued, and each record is retried separately. When the notification worker starts, it reclaims all records left "in progress".
- SMTP allows only TLS or STARTTLS.
- Site management keys can no longer read comment lists or details (they return `403`). They keep only tombstone delete for their own site's comments.
- `trusted_proxies` rejects `0.0.0.0/0` and `::/0`.

## Compatibility

Schema v5 adds the blogger passphrase hash, the blogger mark on comments, and the recipient target field in the notification queue. In v0.1.3, setting a site's blogger passphrase backfills the blogger mark on existing comments by matching the blogger nickname and email.

After upgrading, you need to set a blogger passphrase for the site in the admin console before you can keep posting as the blogger.

## Historical upgrade notes {#upgrade}

This version is archived, with no installation or downgrade instructions. Restoring across schemas requires a complete cold backup matching the target version; changing an image alone is insufficient.
