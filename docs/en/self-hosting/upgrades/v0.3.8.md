# v0.3.8

- Released: 2026-10-09
- Schema: v12 (no migration)
- Image: `ghcr.io/dejavumoe/ecoku:v0.3.8`
- npm SDK: `ecoku@0.3.8`

## Changes {#changes}

- The Go toolchain and container build image are updated to `1.27.2`, and `golang.org/x/net` to `v0.60.0`, together with related dependencies, fixing the HTTP/2, HTTP/1, MIME and TLS vulnerabilities reported by the audit.
- Documentation in all three languages is checked against the source, correcting deployment, backup, REST API and integration instructions, and clarifying HTML attribute values, `pageKey` limits and the requirement to stop the service before importing from Twikoo.

## Compatibility {#compatibility}

- There is no database migration; the schema stays at v12. Compose mounts, configuration keys, environment variables, container ports and HTTP APIs are unchanged.
- Admin and SDK runtime code is unchanged from v0.3.7. Separately installed `ecoku@0.3.7` SDKs can still be used.
- Source builds require at least Go `1.26.0` because of the updated dependencies. The project pins Go `1.27.2` in `mise.toml` and `go.mod`. Container deployments do not require Go on the host.

## Upgrade {#upgrade}

Follow the [upgrade steps](../upgrade#steps): stop the service, take a cold backup, change the image to `ghcr.io/dejavumoe/ecoku:v0.3.8`, then pull and start it.

Check container health, startup logs, comment loading and admin sign-in. If human verification or notifications are enabled, also check verification and delivery. The bundled SDK updates with the image; separately installed SDKs can be pinned to `ecoku@0.3.8` after npm publication succeeds, followed by a website rebuild.

## Rollback {#rollback}

For an instance upgraded from v0.3.7, stop the service, change the image back to `ghcr.io/dejavumoe/ecoku:v0.3.7`, then pull and start it. The schema is unchanged, so no database restore is needed; comments and settings changed after the upgrade are kept. Separately installed SDKs can be pinned back to `ecoku@0.3.7` before rebuilding the website.

Rolling back reintroduces the Go security vulnerabilities fixed in this release. Use it only temporarily while investigating an upgrade issue. If upgrading from an earlier version, first check that version's schema and the [rollback notes](./v0.3.7#rollback).
