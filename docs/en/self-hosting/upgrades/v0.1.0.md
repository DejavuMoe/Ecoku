# v0.1.0

- Release date: 2026-08-15
- Schema: v4
- Image: `git.via.moe/dejavu/ecoku:v0.1.0`

## Changes

First stable release.

- Page keys accept only relative paths on the site.
- The loader and stylesheet URLs can be specified. The container serves `/client/ecoku.css` and the structure-only `/client/ecoku.unstyled.css`.
- The admin console uses the system serif font.

## Upgrade and rollback

Upgrading from `v0.1.0-rc.10`: follow the [upgrade steps](../upgrade#steps) and change the image to `git.via.moe/dejavu/ecoku:v0.1.0`. To roll back, change the image back to `v0.1.0-rc.10`.
