# v0.6.4

- Release date: 2026-11-26
- Schema: v12 (no migration)
- Image: `ghcr.io/dejavumoe/ecoku:v0.6.4`
- npm SDK: `ecoku@0.6.4`

## Changes {#changes}

- The admin comments page gains a search box to the right of **Published** and **Deleted**. It searches the current site and tab by name, email, visitor website, body, post title, page key or `#number`; every word must match, and matches are highlighted. See [Search comments](../../admin/comments#search).
- The admin comment list endpoint `GET /api/admin/sites/:siteId/comments` takes a `q` parameter. With `q`, the counts and pagination cover matching comments only. See [HTTP API](../../reference/api).

## Compatibility {#compatibility}

- The schema stays at v12. When upgrading from v0.6.3, keep your existing data and configuration mounts, container user and healthcheck probe. Configuration keys are unchanged.
- A deleted comment keeps only its post title, page key and number, so a search matches it on those three only.
- Search terms are only sent with the request. They are not written to the page URL or browser storage, and the access log records the route template, not the search terms.
- The npm SDK `ecoku@0.6.4` has the same runtime code as 0.6.3.
- When upgrading from v0.5.7 or an earlier release, read the [distroless migration notes](../upgrade#distroless) and update the old Compose probe.

## Upgrade {#upgrade}

Follow the [upgrade steps](../upgrade#steps) to stop the service and take a cold backup. Set the image to `ghcr.io/dejavumoe/ecoku:v0.6.4`, then pull it and recreate the container. Confirm the container is `healthy`, sign in to the admin and check that the footer shows `v0.6.4`, then search the comments page for the name or text of a comment you know and check that it is found with the match highlighted. Sites that install the SDK from npm should update the dependency to `ecoku@0.6.4`.

## Rollback {#rollback}

Stop the service, set the image back to `ghcr.io/dejavumoe/ecoku:v0.6.3`, then pull it and recreate the container. Both releases use schema v12. Keep your existing database and healthcheck probe.
