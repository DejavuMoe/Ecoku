# v0.4.0

- Released: 2026-10-09
- Schema: v12 (no migration)
- Image: `ghcr.io/dejavumoe/ecoku:v0.4.0`
- npm SDK: `ecoku@0.4.0`

## Changes {#changes}

- The admin console migrates from Vue to Svelte 5, retaining the existing layout, features and Simplified Chinese, Traditional Chinese and English interfaces.
- The comment SDK remains framework-free TypeScript and is published with the matching release version. Its runtime code is unchanged from v0.3.8.

## Compatibility {#compatibility}

- There is no database migration; the schema stays at v12. Existing comments, sites, admin accounts and settings are retained.
- Admin URLs, HTTP APIs, sessions, configuration keys, environment variables, Compose mounts and container ports are unchanged. Container deployments do not require a separate Node.js installation or frontend service.
- Existing website integration code needs no changes, and separately installed `ecoku@0.3.8` SDKs can still be used. Websites using the server loader receive the SDK bundled with the updated container image.

## Upgrade {#upgrade}

Follow the [upgrade steps](../upgrade#steps): stop the service, take a cold backup, change the image to `ghcr.io/dejavumoe/ecoku:v0.4.0`, then pull and start it.

Check container health, startup logs, comment loading and admin sign-in, then confirm that site and notification settings open normally. If the browser still shows the old admin console, refresh the page to reload its assets. Separately installed SDKs can be pinned to `ecoku@0.4.0` after npm publication succeeds, followed by a website rebuild.

## Rollback {#rollback}

For an instance upgraded from v0.3.8, stop the service, change the image back to `ghcr.io/dejavumoe/ecoku:v0.3.8`, then pull and start it to restore the Vue admin console. The schema is unchanged, so no database restore is needed; comments and settings changed after the upgrade are kept. Separately installed SDKs can be pinned back to `ecoku@0.3.8` before rebuilding the website.

If upgrading from an earlier version, first check that version's schema and rollback notes.
