# v0.2.3

- Release date: 2026-09-16 (Git tag)
- Schema: v7, no migration
- Git tag: [v0.2.3](https://github.com/DejavuMoe/Ecoku/tree/v0.2.3)

## Changes

- Saving site settings no longer re-grants blogger status to existing comments. The blogger passphrase gains a "no more than 72 bytes in UTF-8" check; passphrases already set keep working.
- The whole SMTP sending process can be canceled and is bound by a 20-second timeout. If writing back the status fails after a notification is sent, only the write-back is retried; the notification is not sent again. Telegram messages keep complete links and HTML structure.
- Twikoo import restores parent-child relationships correctly even when records are out of order.
- Comments and admin console input support the full range of Unicode characters. Several fixes to cancellation and timeout handling of admin requests, loader retries, Smoji URLs, and keyboard interaction.
- The SDK's `setPageKey(pageKey, pageTitle)` can update the post title at the same time. Omitting the second argument clears the old title.

## Compatibility

Mounts, environment variables, and the password hash format are unchanged. You can upgrade in place from v0.2.2. Comments, config, WAL files, and backups are not cleaned up.

- Existing blogger marks stay as they are. Older releases may have mistakenly marked some comments when saving a site. Those records cannot be told apart automatically from comments actually posted with the passphrase, so this release does not change them in bulk. If you find a mistaken mark, verify and handle it individually.
- Notifications are delivered "at least once": if the process crashes after sending a notification but before recording the result, it may be sent again once after restart.

## Historical upgrade notes {#upgrade}

This version is archived, with no installation or downgrade instructions. Restoring across schemas requires a complete cold backup matching the target version; changing an image alone is insufficient.
