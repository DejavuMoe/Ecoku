# Changelog

## Unreleased

## 0.3.6 - 2026-10-06

- SDK 版本随 Ecoku v0.3.6 发布；生产 SDK 的接口与样式保持兼容。
- 开发演示入口固定使用本机 API，不再接受 URL 查询参数覆盖服务地址，并增加对应浏览器回归。

## 0.3.5 - 2026-10-05

- SDK 版本随 Ecoku v0.3.5 发布；SDK 运行时与 v0.3.4 相同，本版修复仅涉及管理后台菜单切换。

## 0.3.4 - 2026-10-05

- 评论提交遇到网络中断、超时、无效响应或服务端错误时，保留草稿并提示结果尚未确认；不自动重试，避免把可能已经发布的评论误报为未提交。
- 可选身份存储不再阻塞首屏评论加载和发布成功反馈；较晚恢复的身份不覆盖用户编辑，多次保存按提交顺序执行。
- 增加真实浏览器中的 IndexedDB 加密存储、过期、站点隔离和不可用场景检查。

## 0.3.3 - 2026-10-04

- 第 16 层评论不再显示「回复」按钮；服务端以 `422` 拒绝过深回复时显示专门的层级上限提示。
- 加载器读取 `data-i18n` 并传给 SDK；加载失败、初始化失败和超时提示按 `data-i18n`、页面 `<html lang>`、简体中文的顺序选择语言。

## 0.3.2 - 2026-10-04

- `i18n` 参数优先于站点语言，同时作用于 `lang` 属性和 Cap 组件；首屏与首次加载失败的文字也使用该语言。
- 英语、繁体中文下识别服务端的验证失败提示；繁体中文「回覆」按钮与默认博主标志随语言显示。

## 0.3.1 - 2026-10-03

- 评论区支持简体中文、繁体中文和英语，SDK 的 `i18n` 参数覆盖站点默认语言。
- 默认占位文字、排序菜单和无障碍标签跟随语言。
- 取消切页成功提示，保留分页页码播报及发布、错误反馈。

## 0.3.0 - 2026-10-03

- 首次通过 GitHub Actions 发布 npm SDK，版本跟随项目 tag。
- 支持管理员指定 Smoji 图片来源，清单与图片可以分别托管。

- SDK 版本与仓库 release tag 对齐，准备通过 GitHub Actions 发布 npm 包。
- 发表框与已发布正文共用字号和颜色；接入与 SDK 不再显示「正在加载评论…」。
- 可选 `cssURL`：设置后不再注入默认样式。
- 按服务端公开配置在 Turnstile 与自托管 Cap 之间挂载当前 Widget，统一提交单次 `captchaToken`；Cap 资产来自配置实例并沿用官方几何。
- 默认样式改为 v17「纸与墨」；默认 `--ecoku-*` 变量零优先级、可由宿主直接覆盖，新增强调色、圆角、阴影、等宽字体与字号变量；`auto` 继承宿主 `color-scheme`。

## 3.0.0 - 2026-08-13

- 以获批的纯文本、无头像、无线性反应、线程式评论界面替换旧 DOM 模板协议。
- 要求调用方显式提供容器、服务端 URL、站点 ID 和规范页面 key。
- 增加完整线程、墓碑、安全文本渲染、响应式与可访问性交互。
- 收敛包入口：ESM、浏览器 UMD、CommonJS 与类型声明现在各有一致入口。
- 移除客户端 IP/地区采集、management key 及第三方头像/遥测边界。

这是不兼容版本；旧的预置 DOM 模板集成必须按 README 迁移。
