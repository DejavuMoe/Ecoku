# Changelog

## Unreleased

## 0.3.1 - 2026-10-03

- 评论区支持简体中文、繁体中文和英语，SDK 的 `i18n` 参数覆盖站点默认语言。
- 默认占位文字、排序菜单和无障碍标签跟随语言。
- 取消切页成功提示，保留分页页码播报及发布、错误反馈。

## 0.3.0 - 2026-10-03

- 首次通过 GitHub Actions 发布 npm SDK，版本跟随项目 tag。
- 支持管理员指定 Smoji 图片来源，清单与图片可以分别托管。

- SDK 版本与仓库 release tag 对齐，准备通过 GitHub Actions 发布 npm 包。
- 发表框与已发布正文共用字号和颜色；接入与 SDK 不再显示「正在加载评论…」。
- 可选 `cssURL`：设置后不再注入默认样式。
- 按服务端公开配置在 Turnstile 与自托管 Cap 之间挂载当前 Widget，统一提交单次 `captchaToken`；Cap 资产来自配置实例并沿用官方几何。
- 默认样式改为 v17「纸与墨」；默认 `--ecoku-*` 变量零优先级、可由宿主直接覆盖，新增强调色、圆角、阴影、等宽字体与字号变量；`auto` 继承宿主 `color-scheme`。

## 3.0.0 - 2026-08-13

- 以获批的纯文本、无头像、无线性反应、线程式评论界面替换旧 DOM 模板协议。
- 要求调用方显式提供容器、服务端 URL、站点 ID 和规范页面 key。
- 增加完整线程、墓碑、安全文本渲染、响应式与可访问性交互。
- 收敛包入口：ESM、浏览器 UMD、CommonJS 与类型声明现在各有一致入口。
- 移除客户端 IP/地区采集、management key 及第三方头像/遥测边界。

这是不兼容版本；旧的预置 DOM 模板集成必须按 README 迁移。
