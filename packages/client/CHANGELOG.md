## 3.0.0 - 2026-08-13

- 以获批的纯文本、无头像、无线性反应、线程式评论界面替换旧 DOM 模板协议。
- 要求调用方显式提供容器、服务端 URL、站点 ID 和规范页面 key。
- 增加完整线程、墓碑、安全文本渲染、响应式与可访问性交互。
- 收敛包入口：ESM、浏览器 UMD、CommonJS 与类型声明现在各有一致入口。
- 移除客户端 IP/地区采集、management key 及第三方头像/遥测边界。

这是不兼容版本；旧的预置 DOM 模板集成必须按 README 迁移。
